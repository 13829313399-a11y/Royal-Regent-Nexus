# IAM V2 开发交付

本目录记录本地实现与验证。基线为 `a4720a52`。原开发包保存在同目录的 Spec 文件；原文中的计划和验收要求不代表已经完成的事实。

管理员日常使用请先看 [管理员操作说明](管理员操作说明.md)，包含首次确认、调厂调岗、权限设置、兼任支援、离职、交接及常见问题。

## 已实现

- 六个生产厂区与集团职能组织分开；正式主职、兼任、支援和代理使用有起止时间的任职记录。
- 权限绑定关联任职、冻结的权限包版本、明确的厂区上限和在职批次。个人 deny、供应商授权及独立来源分别保留。
- 草稿、权限影响预览、版本校验、独立审批、幂等提交、预约撤回、审计和通知 outbox。
- 冻结立即撤销原会话；离职终止当前和未来来源；复职创建新的在职批次。旧 status 和 system-position 接口不能绕过 V2 流程。
- 人员中心、任职抽屉、办理向导、变更记录、权限解释和转授上限编辑。注册审核与原个人例外入口继续可用。
- 内部报价接管真实修改当前业务负责人，检查报价版本和接管资格，保留历史创建人、厂区和已完成事实。
- 时间边界由请求时的服务器解析器判断；通知和交接物化可重试，不决定权限是否生效。

## 交付边界

`IAM_IDENTITY_WRITES_ENABLED` 与 `IAM_IDENTITY_SCHEDULING_ENABLED` 的代码默认值均为 `false`。开发验收使用隔离库；后续按用户要求修复本机启动，已备份并迁移本机 SQLite 到 `20260926_0125`。当前本机 `.env` 已开启任职办理，保留现有 enforce 授权模式，预约仍关闭；后端重启并验证启用。启用前后原任职资料、角色绑定、来源、个人授权和角色权限的数据摘要一致，未自动为旧用户创建任职。生产环境尚未部署；代码合入仓库不代表已完成生产迁移和启用。

新增迁移为 **20260926_0125**。已有账号数据库即使关闭新写入，也必须先迁移才能启动此版 API；启动检查会明确拒绝缺失结构，避免自动建表掩盖遗漏。

预约的服务端、前端及业务消费者时间边界已完成本地验收，生产启用仍需核实实际配置和人员归属。啤办/生产任务、仓库/订单、纸箱/供应商、3D、UV、喷油六类交接显示“未覆盖，需人工核实”，符合 I45 的覆盖说明要求。历史时点权限解释使用当前账号状态和当前在职批次，不能完整重放离职前的账号或业务状态。

## 验证结论

I01–I68 的规定场景已完成本地验收，详细证据见 [验收矩阵](acceptance.md)。自动化和浏览器测试使用合成隔离数据，本机真实数据库只执行下文所述的启动修复与保持性核对。

- 新增 IAM V2 后端用例：42 项，包含真实 PostgreSQL 并发、SQLite/PostgreSQL 实际升级链、中断恢复、独立进程兼容包回退和 worker 停止时的时间边界。
- 既有后端专项回归：此前 139 项通过；本次追加报价各版本、供应商、旧 IAM/用户管理及密码重置定向回归。各批有重叠，独立结果和日志见矩阵。
- 前端相关单元测试：13 个文件、119 项通过；应用构建和测试 TypeScript 检查通过。
- 浏览器走通存量确认 → 华康 A 工程调华兴仓库 → 提交刷新 → 变更和审计记录；验证 503 恢复、真实 409 重新办理、403 状态、六种视口、Tab/Escape/焦点恢复和 reduced-motion。
- 独立审查发现的完整管理范围、旧办理人缓存、注册系统权限来源和失败恢复问题已修复并定向复测，见 [独立复核](independent-review.md)。

回归中修复了连续办理读到旧任职的界面竞态，以及抽屉末尾 Tab 和关闭后焦点恢复问题。旧通讯录测试固定边界时钟，避免 1 秒余量受登录耗时影响；旧认证测试隔离本机可选模块配置并更新新增响应字段断言，未删除权限隔离断言。

兼容回退包已单独构建并验证，关闭新办理界面和新身份写入，保留 V2 撤权、会话及预约判断。包与摘要见 [验收矩阵](acceptance.md)。本次没有执行整个仓库全量测试、生产发布或物理移动设备测试；实际操作人员按 [迁移与回退说明](migration-runbook.md) 确认生产启用。
