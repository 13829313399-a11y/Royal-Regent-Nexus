统一为一个“权限与组织”工作区。共用导航、标题层级、状态样式、抽屉、对话框和折叠区。

## 2. 主要交互变化

- 点人员姓名或详情按钮打开抽屉；`?person=` 深链接和浏览器前进、后退可以恢复同一人员。
- 办理事项分为三步。保存草稿后，预览失败可以继续原草稿；修改资料会使旧预览及确认失效。
- 提交结果不明确时，先查询原变更单，不自动创建另一张变更单或自动重试提交。
- 核查结果的状态或版本发生变化时，清除原预览，避免用过期凭据继续批准。
- 未保存编辑离开前提示；“继续编辑”保留原人员、申请和输入。提交期间阻止重复提交和离开。
- 弹层打开聚焦标题，Tab 在弹层内循环；Escape 按未保存状态处理，关闭后恢复原按钮焦点，深链接无原按钮时回到主内容。
- 内置职位权限以业务名称、查看 / 操作、数据范围和是否包含为主。技术代码与说明折叠，高风险、失效、缺失定义仍明确展示。
- 导航指示器按真实元素位置计算；页面和步骤使用短过渡，抽屉有进入与退出动画，折叠区使用实际内容高度。
- 网络旧响应不能覆盖新人员或新申请；403 会清除旧的受保护资料、交接项和候选人。

## 4. 保持的契约

- 六条业务 URL、路由权限、原有页面访问策略，以及关闭身份界面开关后的兼容入口。
- 授权和任职的最终判断仍由后端执行；不根据前端标签推算新权限。
- 现有草稿、预览、提交、审批、撤回、交接 payload 与版本约束；预约能力仍读取服务器目录开关。
- 注册推荐职位不会自动选中。内置权限方案保持代码定义和只读。
- 密码找回继续要求身份核验与原浏览器改密；不显示临时密码或 claim 密钥。
- 供应商协作、自审的业务资格和高风险确认要求保留。
- 未适配的工作交接模块仍明确要求人工核实。
- D1 仅给现有个人授权 GET 响应增加 `identity_mode`；读取权限、数据库结构、生产配置和服务器开关保持原状。

### 审计时间的源码核对结果

开发文档建议转换为 UTC ISO，但现有后端对字符串 `created_at` 直接做范围比较，写入格式为 `YYYY-MM-DD HH:mm:ss`。带 `T` / `Z` 的参数可能漏掉同日数据。

本次按实际接口保留空格分隔的日期时间文本，并增加同日过滤回归。界面沿用项目的北京时间口径。没有修改后端的存储、时区和查询逻辑，也没有宣称接口已经支持 UTC ISO 过滤。

- 个人授权 GET 在原读取校验通过后返回 `identity_mode: legacy | v2`，不附加任职历史、人员详情或新读取权限。

## 6. 已知限制与待人工核验

1. **真实 200% 页面缩放未完成验证。** 浏览器控制接口的缩放快捷键没有改变实际 CSS 视口或像素比例；不把该次截图当作 200% 验收。另检查了 683×384 的低可用空间布局，不能替代真实浏览器缩放。请在浏览器菜单设为 200%，核对抽屉关闭、表单聚焦和底部操作后恢复 100%。
2. **系统减少动画偏好未实际开启。** 已检查 `prefers-reduced-motion: reduce` 覆盖规则：关闭过渡、动画和平滑滚动；导航定位不依赖平滑滚动。当前浏览器返回的系统偏好为 false，工具没有媒体偏好模拟能力。需在系统开启减少动画后，再打开 / 关闭抽屉、切换步骤和折叠区，确认无需动画等待且焦点正常。
3. D1 已完成并通过本地验证；旧版服务器仍按未知模式及原服务端校验兼容。线上效果以实际部署版本为准。
4. 审计列表受读取上限与可见范围限制，没有完整总数、全量分页或全量导出。
5. 本次没有提交真实人员变更、注册批准、密码批准或交接动作，也没有实体设备或生产业务验收。
6. 未测量帧率，因此不作“稳定 60fps”承诺。
