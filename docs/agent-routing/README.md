# Codex 默认配置

本项目不设置模型、推理档位、子代理并发上限或自定义角色；`.codex/config.toml` 仅保留说明注释。有效设置继承客户端、用户级配置及 Codex 内置默认值。

原有六角色路由、专用技能、强制分工规则及其校验器已移除。通用开发、验证和 Git 操作要求继续以 [AGENTS.md](../../AGENTS.md) 为准。

项目事实入口见 [检索索引](context-index.md)，源码与验证命令入口见 [仓库地图](repo-map.md)。这些文档不规定代理分工。

当前已运行任务可能仍含旧上下文或显式设置；本次文件恢复不代表该任务已热切换。新建项目任务时核对客户端所选模型。

此变更仅涉及项目层，不更改用户级认证、模型提供商、MCP、插件或权限设置，也不配置业务系统的 AI。

配置继承依据：[官方配置说明](https://learn.chatgpt.com/docs/config-file/config-basic)。
