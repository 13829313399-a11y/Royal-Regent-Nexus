# 给 DeepSeek Harness 的前端开发启动提示词

将下面内容粘贴到DSH，当前会话工作目录必须是UV前端worktree。共同文档放在 `docs/uv-printing/`。

---

你负责在 Royal Regent Nexus 中构建“华康A → 生产部 → UV打印管理”的前端。这不是独立站，不是把旧PocketBase/Vant页面搬进来。我会在worktree验收前端、合并后再让Codex审查和实现后端。

先读取当前工作树的AGENTS.md、PROJECT_MEMORY.md相关完整段落、DESIGN.md，以及：

- docs/uv-printing/UV_PRINT_SHARED_SPEC.md
- docs/uv-printing/UV_PRINT_SOURCE_AUDIT.md

先回报实际工作目录、分支、HEAD、技术栈、拟修改文件和阶段计划。不要把查看当前分支当成已经获得commit/push授权。

共同规格是需求和契约的事实源。先落地contracts与共享的内存fixture/transport，再分阶段构建七个工作区：驾驶舱、生产记录、机台、墨水、人员班次、产品定价、经营报表；包括现场报工模式、来源核对抽屉、质量分桶、库存收发、排班工资预览、定价解释链和经营下钻。大胆优化布局，但不要用满屏同款卡片、无效按钮、假进度、随机图表或一个巨型Vue文件敷衍。

必须保持宿主深青绿企业风与公共组件。页面分层推进，主视图突出，详情渐进展开。首屏让用户看懂“现在要处理什么”，不是只展示统计数。390、1024、1366×768、1440、1920宽下关键操作都要可用。键盘、只读、错误、空数据、保存失败、失联、未定价、0与null全部有明确表现。

你只负责前端模块、类型、样例、前端测试与最小路由/卡片接入。不得修改后端、数据库、全局权限、authStore授权逻辑、旧业务模块、全局主题或.codex/.agents配置。新增依赖先说明必要性，不自动升级现有包。

正式路由严格华康A/production作用域；ModuleCenter不能因activeProductionFactory集团兜底显示UV。新UV正式权限尚未由Codex注册时，不能为了进入页面伪造授权。使用共同规格定义的DEV专属 `/__preview/uv-printing` 和独立mock provider测试全部页面；不修改真实身份，不请求真实UV接口。样例预览只在DEV且显式开关启用，顶部明确标记，生产包不可达。正式入口在后端完成前保持关闭。

所有页面使用同一套contracts和transport。样例操作要改变同一份内存事实并联动汇总，能真实演示新增、核对、更正、失败和重试，不每页写孤立常量。组件不得直接调用PocketBase或硬算正式工资。接口失败不能自动切成样例。设备次数、合格件数、商业价、工价、实际领墨与遥测耗墨严格分开。

先完成F0与F1，运行实际存在的构建/测试并做浏览器检查，修正后继续F2；不要每做一个按钮就等待确认，也不要把未经浏览器检查的页面称为已验收。工具无法完成的检查明确记录，不伪造截图或结果。

交付时填写HANDOFF_TEMPLATE.md：变更文件、契约版本、页面/操作完成情况、真实验证结果、目标视口截图、样例说明、已验收视觉、给Codex的接口与未决问题。未运行写“未执行”。没有我的明确授权，不commit、不push、不合并、不部署。
