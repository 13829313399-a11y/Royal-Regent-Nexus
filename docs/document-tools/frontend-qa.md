# 文档工作台前端验证

## 实现范围

沿用 `/tools` 登录路由、PageHeader、Button、StatusPill、共享 Axios 与主题 token。新增 API 客户端、七方向上下文选项、逐文件上传状态、任务抽屉、后台任务轮询、密码/取消/重试、结果下载与 ZIP 打包。

原文和 PDF 校样使用本地 `pdfjs-dist` 及同版本 worker；只渲染当前高清页，缩略图在可见时低分辨率加载。结果核对使用服务端 200 单元格窗口与 TanStack Virtual；结果值始终使用字符串编辑，保留合并锚点。手动修正提交 `base_revision` 并生成新任务。未加载疑点通过 `target_id` 向服务端请求正确结果窗口。

长页支持水平/垂直切线、毫米/point 输入、拖动、方向键微调、撤销/重做、建议切点草稿、行边界吸附、切片范围预览与内容穿越提示。鼠标坐标经过 PDF.js viewport 逆变换和 scale=1 的可见页变换，不将浏览器像素直接当作 PDF point。

工作台使用容器实测宽度降级：宽容器三栏，中等容器设置抽屉，窄容器工具横向选择且原文/结果单栏。对照模式另以中间 `dt-main` 的真实可用宽度判定：低于 1000px 隐藏并排入口，并从已有对照切回结果；专注模式释放左右轨道后，仍须达到 1000px 才允许并排。原生 dialog 管理模态焦点与 Escape；新增动效遵循 reduced-motion。

## 浏览器与真实转换边界

本前端子任务没有操作用户的浏览器，也没有另启浏览器或改变已有登录状态。真实浏览器上传、转换、下载、跨尺寸截图、完整拖动切点与后端输出坐标比对，由主任务在保持登录的浏览器中独立执行；上述单元测试的模拟 API 不作为真实转换成功证据。

浏览器验收应在源码写入/HMR 停止后刷新开始。Vite 在开发中替换整页模块会重置当前工具和内存文件队列；已提交任务由后端保留，可通过“我的任务”重新打开。

千问与其他引擎状态直接显示服务器返回的“尚未配置 / 已配置但未实测 / 已实测”。质量状态与执行状态分开；“已执行检查通过”不宣称所有未知内容无损。裁切提示保留“改变可见范围，不删除底层隐藏内容”。

主任务已在实际浏览器完成选择器上传、PDF.js 原文/文字层渲染、来源定位、切线指针拖动及键盘微调/撤销、修订新版、任务抽屉和真实 PDF 下载；核对 1538×850、1366×768、390×844 三种尺寸，最终控制台无 error/warn。原文 12.50 与修正版 13.75 的实际文件分别复开检查，旧版哈希保持；650pt 长页切点导出为 650/1150pt 两片。截图与文件证据见 [整体验证](validation.md)。密码、取消/重试与 ZIP 另有真实后端专项覆盖，未把这些 API 证据称作逐项浏览器操作；高 DPI/旋转组合有坐标专项测试，未覆盖所有实体设备。构建和模拟测试不替代上述实物证据。
