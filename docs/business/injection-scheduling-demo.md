# 注塑排产中枢｜领导演示简明讲稿

建议时长：5—8分钟。以华兴厂区的300条模拟订单演示，数量不代表真实生产业绩。

## 一、开场可以这样讲

> 这个模块把“订单排到哪台机、什么时候做、已经做了多少、还差多少、能不能按时交货”集中到一个地方。计划员安排生产，车间记录开工和产量，管理人员可以随时查看进度和交期风险。
>
> 四个厂区使用统一的计划表格式，各厂保留自己的机号和生产记录。设备、模具资料提前维护，日常导入订单后就可以安排生产。

## 二、先让领导看懂三个主要入口

| 入口 | 用通俗的话解释 |
| --- | --- |
| **排产工作台** | 安排生产、看机器、查订单。甘特看时间先后，看板看每台机正在做什么，计划表看订单明细。 |
| **白夜班报工** | 记录每班实际做了多少，更新已啤数、欠数和生产进度。 |
| **基础资料** | 提前登记设备能力、模具参数、实物模具及班次日历，作为排期依据。 |

## 三、现场按这六步演示

### 第1步：看全厂情况

**操作：** 选择“华兴”，点击“清除筛选”，再切到“看板”。

**讲解：** “这里可以看每台机器正在做哪一单、下一单是什么，以及待排订单和交期风险。”

本次测试共300条订单：初始270条排在45台机器上，每台6条队列；另外30条留在待排区。经过开工、报工和排产操作后，页面数字会继续变化。

### 第2步：说明Excel怎样接入

**操作：** 在“计划表”查找一个测试单号，展示机号、计划数量、已啤数和欠数。需要展示导入时，可打开“导入 Excel”查看预览；这批数据已经导入，无需再次应用。

**讲解：** “现场仍可以沿用熟悉的Excel。表里已经排好机器的，系统保留机器和先后顺序；没有排机器的，进入待排区。”

预览中的“跳过”勾选框表示不导入该行。核对无误后，才点击“应用所选需求”。

### 第3步：演示自动排产和未排原因

**操作：** 打开排产范围，选择“仅未排需求”，先点“仅预览”，查看结果，再点“计算并保存”。

**讲解：** “系统结合机台能力、模具是否可用、日产目标、班次和交期来安排顺序；排不进去的订单会告诉我们原因，方便处理。”

当前剩余的6条是特意设置的测试单：待料、待通知、暂停各2条。可选其中一条，将需求状态改为“可排”并保存，再排产，展示处理前后的变化。

### 第4步：演示单台或批量开工

**操作：** 在看板选择待开工机台，点击“开工”；也可以勾选几台，点击“批量开工”，核对后确认。

**讲解：** “排好计划后，由现场确认开工。多台机器可以一起操作，但每台只启动队列第一批，后面的订单继续排队。”

**这里要说明：导入计划不等于已经开工；实际开工后才显示在产。**

### 第5步：演示报工和进度变化

**操作：** 打开“白夜班报工”，选择生产日期和班次，找到一条已开工的测试订单，输入本班累计啤数并保存。

**讲解：** “车间每班填实际产量，系统就能算出已经完成多少、还欠多少，并据此更新后续预计时间。”

可以用下面这个小例子讲解：

| 操作 | 订单累计已啤 | 欠数 |
| --- | ---: | ---: |
| 计划1,100啤，导入前已做900啤 | 900 | 200 |
| 本班累计填100并保存 | 1,000 | 100 |
| 同一班次改成200并保存 | 1,100 | 0 |

**报工填“本班累计数”。** 从100改成200，本班合计就是200；导入前已有的900啤不用再报一次。

测试单“旧2 / THX0910-001”初始就是这个例子；若已经做完，可换一条仍在产的测试单演示。

### 第6步：完工、接下一单、查看交期

**操作：** 报工后在批次详情中确认完工，回看机台下一批任务；再切到甘特或计划表查看时间和交期风险，最后展示“导出”入口。

**讲解：** “从导入订单、安排机器、开工、报数到完工，都有连续记录。管理人员既能看当前进度，也能找出需要协调的订单。”

## 四、领导可能会问的几个问题

**为什么有些订单不自动排？**

待料、待通知、暂停、修模等订单需要先处理状态；设备或模具条件不满足时也会显示原因。导入时，模板E列和AS列的备注会参与状态识别。

**公共模具库和实物模具有何区别？**

公共模具库存参数，例如模号、名称、适用机型和日目标；实物模具记录实际有哪一套、在哪个厂、能否使用。本厂设备则记录每台机器的规格和能力。这些都是常驻资料。

**全自动、吸盘和夹具没填，会不会影响排期？**

不会仅因此阻止排期。全自动状态和可装卸夹具作为现场生产准备信息记录。

**导错表能否重新来？**

可以通过“更多 → 清空本厂计划数据”处理。它清除当前厂区全部计划数据，保留设备和模具等基础资料；已有开工、报工时需要额外确认。演示时介绍入口即可。

## 五、结束时可以这样讲

> 这个模块的主要作用是：让计划安排看得清、现场进度跟得上、异常原因找得到，便于计划员、车间和管理人员使用同一份数据协调生产。

演示前只需确认：厂区是华兴、已清除筛选、准备好一条可开工或可报工的测试单。具体数字以演示时页面为准。
