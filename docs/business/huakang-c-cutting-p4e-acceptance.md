# 华康 C 裁床部 P4e：月结报表与冻结导出

本批提供只读 Excel 导出，沿用 P4b／P4c／P4d 证据和独立查询权限。无需新增迁移，不自动授权员工或改变业务数据。

## 报表及入口

裁床部 → 月结，在对应区域选择记录，点击“预览 Excel 导出”，核对范围和状态后“确认下载 Excel”。

| 报表 | 可用依据 | 内容 |
| --- | --- | --- |
| 内部月结冻结表 | 明确选择的已锁月事件 | 分币种费用汇总、生产汇总、物料收发耗存、完工与在制归集、冻结来源索引、跨月事项、确认声明和版本操作记录 |
| 外发结算冻结单 | 明确选择的已确认结算事件 | 加工厂、确认凭据、验收明细、冻结含税单价、部分结算数量与金额、原报价及验收版本 |
| 付款登记及当前未付余额表 | 当前有效付款／结算事实 | 所选月付款登记及分配明细；当前全期有效应付、已付、未付、待复核占用及可继续核销余额 |

付款月份只限制登记明细，不限制当前全期余额。付款表不是历史月末报表，不新增付款锁月；草稿和已冲销记录可追溯，但不计已付，待复核只占用。

## 冻结、权限与并发

- 内部正式报表拒绝草稿／待复核版本；外发正式报表拒绝未确认版本。反结后仍可选择原锁月／确认事件导出，显著标记“历史失效冻结版本”，不计当前有效金额。
- 数量、单价、金额来自所选快照，后续调价、补录或重新锁月不改旧版。快照校验值不变；当前状态、导出人及时间属于本次导出说明，不承诺 XLSX 每次字节相同。
- 正式报表覆盖整月／整张结算单，不沿用页面显示筛选，防止漏项。付款余额按各币种独立汇总，不跨币种相加。
- 内部报表要求 `read`＋`cost_read`；结算报表要求 `read`＋`settlement_read`；付款报表要求 `read`＋`payment_read`。保持原厂区和部门限制，无隐式授权。
- `POST /api/cutting-operations/exports/preview` 生成依据摘要；`exports/download` 重新授权和取数，要求摘要一致。按裁床事务锁取得数据副本后释放锁生成文件，返回前再次核对真实会话、权限与报表摘要，变化则409／403／401拒绝下载。
- 前端在选月、选版本、父级处理状态、权限和会话变化时清除预览并中止旧请求；文件返回后再次读取权限，不保存失效响应。接口返回 `Cache-Control: no-store`，不建立浏览器业务缓存或服务端公开下载地址。

## 来源与历史追溯

- 生产来源的业务日期、操作人和操作时间按冻结记录的真实结构读取；旧记录只有操作人ID时直接保留ID，不借用今天的员工姓名。
- 每条来源标明期初／本期／后续期间及冻结时记录状态；保留仓库关联原单、耗用原单／替代单、生产同单前次／后次生效事件。历史、草稿、作废和操作记录只供追溯，不应逐行累加为本月数量。
- 原冻结版的操作记录保留至原冻结时点；后续反结、重结的操作者、时间、原因及当前有效冻结事件另列，不改原版数量和金额。

## 文件规则

- 含厂区、期间、截止日期、编制／冻结／导出人、版本、来源事件、快照及报表依据校验值。历史失效标识出现在各表标题中。
- 金额和小数数量保存为精确文本，前导零货号不丢失；不生成 Excel 公式。以等号等开头的原始凭据仍为文字。零与未知值分别保留。
- 同一份完整报表自动按明细行、单元格和文本容量分卷：每张分表最多两万数据行、单卷预留说明及清单后不超过四十万单元格。单卷返回 Excel，多卷一次返回 ZIP；各卷附连续原表行号与总行数，压缩包另附各文件 SHA-256 清单，共用同一报表依据校验值。分卷不改变冻结版本、不重复汇总、不随页面筛选漏项。单文件最多20MB、整包最多100MB、在线来源最多两百万单元格／100卷；技术上限仍明确拒绝整份下载，不返回部分成功文件，也不提示不存在的筛选操作。超过32767字符或含非法控制字符的单元格明确拒绝。
- 首卷增加引用原汇总的打印摘要，不能再次累计。使用冻结表头、筛选、居中换行、A3横向打印及重复表头。宽明细保留100%字号并横向分页、重复首列；每页标明期间、表名和有效／历史状态，正文按内容增加行高。超长凭据保留完整电子文本，打印行高有上限，须在电子文件中查看。未实现 PDF、原工作簿的精确套印版式、服务端永久导出归档或银行操作。
