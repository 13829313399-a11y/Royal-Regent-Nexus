# T05a／T05b 需求试算与订单依据草稿实施说明

采购填期与业务自审基础已接续实现，当前流程、权限及验证见 [T05c 实施说明](huakang-c-material-plan-workflow.md)。本文保留试算与订单关联的实现范围。

本批承接工程基础，实现无需真实库存表的业务试算。主线为：选择当前有效工程 BOM → 可选关联订单中心记录 → 输入试算数量与损耗 → 核对逐工序用料和同属性汇总 → 保存个人草稿及不可变历史。订单关联只固定依据，不形成申请单、采购单、订单下发或库存占用。

## 实施合同

1. 新增 `material_plan:read`、`material_plan:draft_write`，限定华康 C 业务部，按创建人隔离草稿；不自动给岗位授权。复用有效工程 BOM 与物料快照，不给业务工程编辑权。
2. 使用精确分数逐路径展开，再在每个用料出现行单独乘以数量和损耗。父项损耗不传递到子项；成品根项只作为数量基准。仅相同物料、版本、单位和本次物料属性汇总，保留工序和出现行。同编码的自制与委外必须分开，不混属性、单位或历史版本。
3. 普通物料免损默认沿用工程设置，业务可覆盖；非根客供物料必须使用订单统一损耗率，不允许免损，即使本次损耗率为零也不能勾选。新选择 BOM 时客供默认计损；历史及旧草稿不自动改值，业务须显式修正后保存。试算／保存／提交／自审均由服务端重新校验，已完成原请求的重放仍返回当时记录。库存、在途、物料期仍待核实，未关联订单的草稿另提示订单绑定；采购数量为未计算，不能将未知值当成零。
4. 选择及保存均重查有效 BOM。工程草稿修订不撤销当前有效版；新有效版发布后，旧试算历史保留，但再次保存需明确选择新依据并重新核对免损项及物料属性。
5. 新增独立草稿和事件表，迁移接续 0190；默认开关关闭，启动不自动建表。保存固定 BOM、物料与计算快照，使用创建人、内容及请求编号绑定的重试和版本检查。锁序为工程厂区锁 → 试算厂区锁，不获取或改写库存分配账。
6. 计算保留精确分子／分母；展示小数必要时标约数，不能用展示值作后续采购取整依据。整数采购、抵扣和单位换算在真实数据合同接通后计算。
7. 业务逐用料行选择本次自制／委外，默认沿用工程物料属性；外购、客供沿用工程依据。业务选择不改物料编码、负责部门、档案默认属性或 BOM。保存完整逐行属性及计算结果，历史直接读取原快照；旧请求仍可按原内容重放，旧草稿再次编辑时补齐工程默认值。新计算版本为 `gross-fraction-v2-attribute`。

## T05b 订单依据关联

- 本轮计划与交付：复用客户订单中心身份和 revision → 新增可选关联及服务端校验 → 保存最小订单快照和未放单门槛 → 补权限、变更、历史与界面回归。无需物料／库存／采购表格，无新迁移。
- `/api/material-planning/orders` 仅返回华康 C、有效且数量已填写的订单。需同时拥有试算读取及华康 C 业务部 `customer_order:read` 的明确授权；不回退为其他部门的同名权限。按订单号、货号或客户名称作字面查询，最多 50 条，超过提示缩小范围。
- 请求仅接收 `order: {line_id, revision}`，不接受客户端声称的订单数量、状态或客户。计算及保存重新读取权威订单；拒绝跨厂、旧 revision、取消、未知数量、货号不一致和试算量超过订单总量。数量由业务填写，不自动将待交量当作生产欠数，不转换订单与 BOM 单位，不计算可再次放单余量。单位口径、拆单及旧新下发互斥仍属正式放单联调。
- 顺序为工程厂区锁 → 试算厂区锁 → 订单行锁；SQLite 使用事务写锁，PostgreSQL 使用订单行锁与现有订单更新串行。只读取订单，不增加其 revision，不创建下发或走货记录。PostgreSQL 实机并发验收仍待完成。
- 草稿结果保存当时的订单身份、客户、货号、数量、已走货量、状态及 version/revision，不复制订单内其他商业字段。源单变化后新计算／保存需重新选择核对，历史及原成功请求仍返回当时快照。
- 关联草稿及其历史、重试均需要当前订单查看权限；撤权后列表隐藏关联草稿，禁止通过旧 ID 重开；前端即使后续刷新失败也清除已显示的订单依据。
- `release_gate.can_release` 固定为 false。未关联时另缺订单依据；库存核实、有效在途分配和正式放单流程始终列为缺项。T05c 填齐工序日期后移除日期缺项；原业务自审后仍保持不能放单。此字段不是可由前端覆盖的批准。业务自审不生成申请、库存占用或供应商下发。
- **正式放单合同**：后续业务自审、申请和采购分组必须继续按本次物料属性区分，同码自制／委外不能合并；不得在下游再次仅按编码汇总。本批通过关联真实订单身份的隔离测试验证分组仍为自制 105／委外 21。

## UI 简报

- 路由 `/modules/sales-business/material-planning?factory=huakang-c`，华康 C 业务目录新增严格授权入口。
- 沿用 PageHeader、SectionPanel、Button 和全局颜色／字体，参考工程基础工作区与业务模块壳。首屏为“我的草稿”和新建；编辑区展示有效 BOM、试算数量、统一损耗、免损清单。
- 计算明细与同物料同属性汇总分区展示；编辑区并列显示工程默认属性和本次属性，汇总表显示本次属性。数字与单位成对出现，不展示跨单位总量。历史只读展示当时的依据和数量。业务页显示当前草稿／填期／自审状态，流程按钮见 T05c；没有正式下发按钮。
- 加载、无权限、尚未部署、无有效 BOM、空草稿、失败、保存未知及成功均有明确反馈；未知写入保留原请求重试，切换身份清理私有数据，迟到响应不能恢复旧内容。
- 任何输入变化清除旧试算结果；切换 BOM 重置免损覆盖及本次物料属性并提醒核对。离开有改动草稿需确认；未知写入期间禁止页面内切换。强制关闭浏览器仍可能丢失内存草稿。
- 表格局部横向滚动；工具栏窄屏换行；原生标签关联控件。浏览器应检查桌面及 DESIGN.md 断点、键盘、错误和受限状态。当前 DevTools 工具缺失，视觉验收不可用，单元测试不替代浏览器结论。

## 验收计划

验证 100 加 5%＝105；加工 100／布料 20 各加 5%＝105／21；父项免损不隐式传给子项；0.0297÷2 两片仍为 0.0297；相同线料同属性跨工序汇总、不混属性版本单位；同编码自制105与委外21分开，改为同属性后合计126；精确分数避免 1/3 叠加偏差。另验证旧版禁选、快照不变、旧请求兼容、非法属性调整拒绝、并发保存与重试、身份／厂区／部门隔离、显式拒绝、迁移保护及前端迟到响应。

真实库迁移、启用、员工名单、正式订单放单／余量控制、采购申请、库存与在途抵扣、采购整数及下发仍待实施；采购填期和内部业务自审已由 T05c 接续实现；仍按 T05 后续及 T06～T08 推进。

## 实现结果

- 已建立业务部独立入口、本人草稿列表、有效 BOM 选择、数量与损耗输入、逐行免损、工序筛选、同料汇总、保存及历史。
- 后端计算与保存均重新核对当前有效 BOM。业务不能提交自己的替代 BOM 树或计算结果；来源由服务端取工程已审核快照。工程继续编辑草稿时，上一有效版仍可使用。
- 旧试算保存失败时保留输入供核对；切换到新 BOM 明确提醒重置免损项和本次物料属性。保存结果未知时保持原路径与请求编号重试，禁止竞争编辑。
- 接口省略免损覆盖时仍继承工程默认；保存时展开为完整 map，打开历史缺省 map 时页面亦补齐，避免“显示计损、实际免损”。
- 所有供给数据仍为待核实，采购数量为空值；试算结果包含精确依据与展示约数。成品数量不会因材料损耗而变成新增客户订量。
- 工作区查询只获取本人每份草稿的当前事件，历史按需读取；大规模分页与性能尚未验收。输入使用有限非负数及精度限制，数量最大一亿、最多 12 位小数，统一损耗率支持 0～100%。
