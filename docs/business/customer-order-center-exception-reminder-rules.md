# 客户订单中心异常与提醒规则

> 文档版本：V0.1
> 文档状态：静态原型规则草案
> 当前阶段：只实现前端展示，不发送真实通知
> 适用范围：订单数据台账、厂区总排期、下游生产反馈

## 1. 目的

异常与提醒中心用于集中回答：

- 哪些订单数据还不能确认；
- 哪些PO即将到期或已经逾期；
- 哪些临期订单生产尚未完成；
- 哪些订单尚未供生产部门调用；
- 哪些生产模块使用了旧需求版本；
- 哪些下游任务长期没有反馈。

提醒中心只负责发现、分类、展示、标记关注和跳转处理，不成为第二套订单或生产台账。

## 2. 权威数据来源

| 异常类别 | 权威来源 |
| --- | --- |
| 订单字段缺失/冲突 | 客户订单中心订单版本 |
| 客要求走货期 | 客户订单中心17个基础字段 |
| 临期/逾期 | 客要求走货期与当前业务日期计算 |
| 是否可供下游调用 | 订单确认状态和当前版本 |
| 生产状态/完成数量 | PMC或生产模块 |
| 未完成原因 | 对应生产模块 |
| 下游使用版本 | 下游接收/生产任务记录 |
| 实际走货/关闭 | 未来仓库或走货模块 |

提醒中心不得允许用户直接修改这些权威字段。

## 3. 异常分类

### 3.1 订单数据

- 必填字段缺失；
- PO、合同或产品身份冲突；
- 客要求走货期待确认；
- 非整箱等阻断问题；
- 订单变更尚未确认；
- 当前版本不可供下游调用。

### 3.2 交付风险

- 未来30天即将到期；
- 未来7天临期；
- 客要求走货期已过但订单未关闭；
- 生产预计完成日期晚于走货期；
- 走货日期变更但下游仍使用旧日期。

### 3.3 生产反馈

- 已发布但下游未接收；
- 已接收但未开始；
- 生产部分完成；
- 生产受阻；
- 临期但生产未完成；
- 下游超过规定时间未反馈。

### 3.4 版本状态

- 下游使用的 `demand_version` 不是当前版本；
- PO已变更但生产任务仍引用旧版本；
- 同一任务反馈的版本顺序异常。

## 4. 优先级

| 优先级 | 页面标签 | 建议条件 |
| --- | --- | --- |
| P0 | 紧急 | 已逾期未关闭；7天内走货且生产未完成；关键订单数据阻断且交期已到 |
| P1 | 警告 | 7天内走货；生产预计完成晚于走货期；下游版本落后 |
| P2 | 关注 | 30天内走货；生产中或部分完成；下游短期未反馈 |
| P3 | 信息 | 订单已发布、下游已接收等无需立即处理的状态 |

静态页面当前展示“紧急、警告、关注”三档，不展示普通信息状态。

## 5. 日期阈值

当前草案：

- `days_to_ship > 30`：计划中；
- `8 <= days_to_ship <= 30`：即将到期；
- `0 <= days_to_ship <= 7`：临期；
- `days_to_ship < 0` 且订单未关闭：逾期。

以上是公司级规则草案，不属于BuzzBee模板，后续应支持配置。

## 6. 去重与主异常

同一个 `delivery_demand_id + demand_version` 可能同时命中多条规则。

页面默认只显示当前主异常，优先顺序：

1. 订单数据阻断；
2. 已逾期；
3. 临期且生产未完成；
4. 临期；
5. 下游版本落后；
6. 生产受阻或未完成；
7. 即将到期；
8. 长时间未反馈。

异常详情可以保留其他命中规则，但列表不重复生成多个相同业务项。

建议异常唯一键：

`delivery_demand_id + demand_version + primary_rule_code`

## 7. 提醒状态

| 状态 | 含义 |
| --- | --- |
| `OPEN` | 新产生，尚未关注 |
| `ACKNOWLEDGED` | 用户已看到并关注 |
| `ESCALATED` | 风险等级升级 |
| `RESOLVED` | 权威数据已变化，规则不再命中 |
| `REOPENED` | 已解除后再次命中 |

重要原则：

- “标记已关注”不等于已解决；
- 用户不能手工把真实异常改成已解决；
- 只有权威订单、日期、生产或版本数据变化后，系统才能自动解除；
- 风险等级升级后，即使此前已关注，也应重新提醒。

当前静态页面只演示 `OPEN` 与 `ACKNOWLEDGED`。

## 8. 建议处理路径

| 异常 | 处理页面/责任模块 |
| --- | --- |
| 订单字段问题 | 客户订单中心“预览与确认” |
| PO变更未确认 | 客户订单版本与变更 |
| 临期/逾期 | 客户订单中心查看，跟客协调 |
| 生产未下发 | PMC或未来发布中心 |
| 啤机未完成 | 啤机排产/执行模块 |
| 喷油未完成 | 喷油排产/执行模块 |
| 装配未完成 | 装配排产/执行模块 |
| 版本落后 | 对应下游重新读取当前版本 |
| 实际走货未回填 | 仓库/走货模块 |

提醒中心只负责跳转，不复制处理表单。

## 9. 页面指标

- 全部待关注；
- 紧急；
- 交付临期/逾期；
- 订单数据阻断；
- 生产跟踪；
- 下游版本落后；
- 已关注但未解除；
- 今日新增；
- 今日已自动解除。

静态第一版先实现前六项。

## 10. 权限

| 操作 | 跟客 | 业务主管 | PMC | 生产部门 |
| --- | --- | --- | --- | --- |
| 查看自己客户/厂区提醒 | 是 | 是 | 按厂区 | 按厂区/部门 |
| 标记已关注 | 是 | 是 | 是 | 是 |
| 修改订单字段 | 按订单权限 | 是 | 否 | 否 |
| 修改生产反馈 | 否 | 否 | 按PMC模块 | 仅本部门模块 |
| 配置提醒阈值 | 否 | 公司授权 | 公司授权 | 否 |
| 手工标记已解决 | 否 | 否 | 否 | 否 |

## 11. 未来通知渠道

真实功能阶段再决定：

- 系统站内通知；
- 模块首页红点；
- 每日风险摘要；
- 邮件或企业通讯工具；
- P0风险升级通知。

同一异常应有通知去重和冷却时间，避免反复轰炸用户。

## 12. 静态页面验收

- 导航存在独立“异常与提醒”入口；
- 能显示紧急、警告和关注优先级；
- 能按优先级、分类和关键词筛选；
- 同一订单默认只显示主异常；
- 能看到客户、PO、产品、走货期、生产状态和需求版本；
- 能查看订单详情；
- 能跳转到正确处理页面；
- 能标记已关注及取消标记；
- 页面明确“标记已关注不等于解决”；
- 页面不能修改订单字段或生产进度；
- 30天/7天规则明确标注为待确认草案。
