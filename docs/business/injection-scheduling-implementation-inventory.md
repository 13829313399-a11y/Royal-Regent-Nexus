## 4. 0087 前向扩展契约

`20260831_0087_connect_injection_schedule_application.py` 接在远程主线的纸箱收货 0086 后，只增加注塑应用层确实需要、且 0085 没有等价表达的字段：

- 厂区设置：排程总 revision、默认时间范围、冻结时长、有效生产小时、排程规则 JSON、颜色规则 JSON。
- 导入批次：文档类型、profile code、单据头/页尾公共字段 JSON。
- 订单需求：稳定业务键、来源行号、总套数、整啤件数/倍率、原始与归一化机安、色系/明度、喷油、预计用料、交货地点、下单人/操作员、完整性状态。
- 机台：原始安数标签、高速机标记、显示顺序；归一化安数继续复用 `machine_ounce_capacity`。
- 模具：原始机安标签、整啤件数和倍率；归一化机安继续复用 0085 的机安字段。
- 排程行：厂区排程 revision、来源、实际开始/完成、分配解释、人工调整原因。
- 新表：`injection_schedule_machine_unavailable_windows`，表示维护、故障、停电、模具维修和临时停机。

已啤数、欠数、完成率、预计用料、预计入库、交期差和风险等级由后端 read model 计算，不新增多个可被前端分别写入的副本。

## 5. 稳定业务规则

- 所有正式查询和写入必须带后端验证过的 `factory_id`；前端参数不是授权依据。
- 权限族保持 4 项：`injection_scheduling:read|edit|schedule|admin`。
- 数量、重量、安数使用 Decimal/Numeric；货号、工模、单号和色粉号保留前导零。
- `qualified_shots = max(reported_shots - defect_shots, 0)`。
- `remaining_shots = max(order_shots - sum(qualified_shots), 0)`；目标缺失或为 0 时不得除零。
- 班次记录按排程行、生产日期、班次 PUT/upsert；夜班跨日归属由厂区班次配置计算。
- 自动排程必须先硬约束、再分层优先；同输入、规则版本和算法版本必须可复现。
- proposal 只允许预览、确认应用或拒绝；输入版本、锁定项或厂区 revision 变化后必须失效。
- Qwen 只产生经过 schema 校验的结构化建议，不直接写正式排程。

## 8. 文员操作简表

1. 在生产模块中心进入“注塑排产中枢”，先确认右上角实体厂区。
2. 上传 `.xlsx/.xlsm` 后只生成预览；先看新增/更新/重复、阻塞和警告。阻塞不为 0 时，修正来源表或由管理员补齐模具主数据后重新上传。
3. 预览无阻塞后点击“确认写入订单”；重复确认使用同一 request id，不会重复建单。
4. 人工排产先选订单、机台和开始/完成时间，点击“校验移动”；只有校验通过后才能确认。
5. 已确认任务可锁定；白夜班按日期登记总啤数和不良数，系统派生合格数、欠数和完成率。
6. 自动排程必须先看 proposal 和未排 reason code，再人工确认应用；锁定项、冻结区和材料未齐订单不会被移动。
7. 当前搜索、状态和优先级可保存为个人视图，并按同一筛选导出 Excel。

## 9. 部署变量与迁移/回滚

- 核心模块不依赖 AI。默认 `QWEN_ENABLED=false`；启用时配置 `QWEN_API_KEY`，可选 `QWEN_BASE_URL`、`QWEN_MODEL`、`QWEN_TIMEOUT_SECONDS`。
- 其他环境（尤其生产）迁移前必须对目标数据库做一致性备份并验证可恢复，再执行 `alembic upgrade 20260831_0087`；应用启动的 schema guard 会拒绝“已有 Alembic 库但未到 0087”的运行状态。
- 本地升级的可恢复备份为 `D:\RR\.backups\royal-regent-nexus\royal_regent_nexus-before-0086-20260831-184111.db`，SHA-256 为 `B90516249AACCBF64E33FDECA9B699FB55BD5BEEFC8C73ADD0DCE016325CD9DE`；备份保持 0085、`quick_check=ok`、外键异常 0、用户 26、注塑业务行 0。
- 0086 downgrade 只允许在扩展表完全无业务数据时执行；一旦存在注塑排产数据，应恢复迁移前备份，而不是强制降级丢数据。
- 正式接管仍按“主数据校准 → 当前计划导入 → 影子排程 → 双轨 3–5 个工作日 → 系统接管”执行；未经文员核对和负责人签收，不得停用原 Excel。

## 10. 发布边界
