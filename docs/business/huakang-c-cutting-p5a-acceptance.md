# 华康 C 裁床部 P5a 首批：历史期初核对与切入准备

## 交付与边界

月结工作区新增只读准备区，切入日为所选月份1日，期初截止为前一天。通过 `POST /api/cutting-operations/cutover/preview` 回放最新有效事实；当前补录、更正及反结会改变新预览，本表不宣称是当时已知事实或冻结期初。

| 范围 | 当前核对 | 权限 |
| --- | --- | --- |
| 内部 | 原实发现场余料、已发未签、余料费用、上月有效冻结在制、合格完成／未交接、外发未收回／待验收、散片 | 裁床读＋材料成本读 |
| 财务 | 切入前所属月有效应付减切入前有效付款；切入后付款单列；切入前验收尚未计入同期有效结算的套数 | 裁床读＋结算读＋付款读 |

- 在制只从紧邻上月当前有效锁月归属取数，并校验正常耗用与现场结存；反结后的旧版本不会继续作为有效期初。无冻结依据时未知，不以今天归集替代。
- 余料费用无上月有效冻结依据时按当前已确认批次价试算，明确标识非冻结。缺价为空，明确零价保持已知零值，币种分开。
- 结算按所属月筛选，付款按实际业务日期筛选，采用当前有效记录。未确认结算不计应付，待复核付款不计已付；切入前付款对应后期结算时提示人工核对。验收未结数量不自动估价为应付，也不是今天可结数量。
- 对照值必须有资料依据并与系统行同单位／币种；重复或陌生映射拒绝，差额为对照值减系统值，不与流水叠加。尚不能映射的账外事项单列。
- 差异请求绑定当前批次数值、相关提示及凭据链；不纳入全厂流水版本、当前在制归集或无关后期付款草稿。相关补录、更正、改价、反结及冲销仍返回409。刷新和换批保留本页输入，返回批次须重新核对；本批不再出现的映射明示，单位变化须清空旧对照再核实。权限按草稿所属范围检查，无权限范围禁选；父区刷新不清除仍有权限的草稿；权限读取失败时隐藏结果并保稿，重新校验后恢复，明确撤权及会话边界仍清除。改变月份、范围、范围查询或每批数量须确认丢弃。
- 本批没有数据库迁移、业务写入、正式期初登记、草稿持久化、文件导入或生产发布。输入只在组件内存，关闭／刷新仍可能丢失；权限撤销和会话边界清除输入与结果。
- 支持范围查询、每批1～200项（默认50）、首批恢复和本批明细筛选。内部仅筛选截止日前有生产／实发历史或上月冻结依据的订单；财务数值行及凭据链分别作为批次项目。界面明确覆盖总数、批数及当前批次，不能推断全量已核对。单批数值及历史事件超过10000项整批拒绝；缩小每批数量或查询范围后重试。全厂来源锁及物料／财务历史扫描仍存在，不能视为大规模性能验收。
- 财务追溯保留原确认、反结、冲销、后继更正的操作者、日期、原因、凭据及金额，旧版本不计数。来源入口定位具体订单／任务／实发、结算或付款版本，沿用目标工作区权限与未保存操作保护；同页打开财务凭据不丢弃期初输入。
