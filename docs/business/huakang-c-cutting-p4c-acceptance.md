# 华康 C 裁床部 P4c 首批：外发加工费对账与结算

对应方案：[第 16.2 节 P4c 首批](huakang-c-cutting-module-plan.md#p4c-首批外发加工费对账与结算)。

## 已确认口径与本批范围

- 按外发已验收合格套数计费，可部分结算、跨月续结；自报、未验收、超任务额度不自动计费。
- 裁床主管单独授权确认每任务含税单价、币种及报价凭据；CNY／HKD／USD 分别处理，不自动拆税、汇兑或另加运费和扣款，零价亦须依据。
- 主管编制对账，登记外厂确认凭据，提交会计独立复核；确认后冻结结算单及应付。付款登记与核销下一批实施，不自动操作银行或发送外厂消息。
- 我方材料费用与外发加工费分别归集。内部月结与外发结算是独立状态，本批不把确认应付当成已付款或完整任务成本已结清。
- 当前报价入口位于已有合格验收的待结明细；验收前合同报价、按裁片报价、超产付费审批、扣补款／贷项、发票管理及历史期初应付不在本批。

## 操作路径

1. 月结工作区 → 外发加工费对账与结算 → 选择对账月份 → 查询待结验收。当前月截至当天，历史月截至月底，包含更早尚未结算的验收。
2. 主管按任务确认含税单价和报价依据。已确认历史结算保持原价，未确认草稿价格变化后须重新核对。
3. 新建对账草稿，逐验收填写本次套数。每单一家加工厂、一种币种；允许多个订单，不自动填满全部可结数量。
4. 填写外厂确认凭据及编制原因，先预览本次套数、明细金额及合计，明确勾选外厂已核对本版数量、含税单价、币种和金额后保存并提交。可不勾选先保存草稿，但不得提交；改数量、改凭据、调价或刷新依据后须重新预览确认。草稿不占用，提交后占用原验收；各行共享任务剩余额度，不能逐行累加突破总额度。
5. 会计核对验收、价格和外厂凭据，填写复核依据，确认应付或退回。编制／提交人与确认人须不同。
6. 错单由单独授权会计填写原因反结，保留旧快照，再编制、提交、复核。有同验收同报价后续占用时，按页面列示的月份、单号、状态及占用套数逆序定位处理；先退回或反结后续单。

## 权限

全部限定华康 C，并要求 `cutting_ops:read`。

| 岗位 | 权限 | 边界 |
| --- | --- | --- |
| 裁床主管／会计查询 | `settlement_read` | 独立加工费查询；材料 `cost_read` 不替代此权限 |
| 裁床主管 | `settlement_price` ＋ `settlement_read` | 确认／修订任务含税报价 |
| 裁床主管 | `settlement_prepare` ＋ `settlement_read` | 编制／修订／提交对账 |
| 会计部 | `settlement_confirm` ＋ `settlement_read` | 独立确认应付或退回 |
| 会计部单独授权人 | `settlement_reopen` ＋ `settlement_read` | 有原因受控反结 |

表中动作统一使用 `cutting_ops:` 前缀。不自动授予员工、采购或外厂账号权限。验收沿用既有 `acceptance_write` 岗位边界；实际员工仍需业务指定。

仅 development 的现有 `user-admin` 在明确开启 `CUTTING_PERIOD_ADMIN_ACCEPTANCE=true` 时可验收两个岗位，冻结单显示本地验收标记，不能当成真实双人复核验收。

## 追溯、金额和并发

- 原验收文档、生效版本、冻结订单／任务／BOM／执行方、报价版本、确认人、外厂凭据和操作原因保存在不可改删事件及快照中。
- 金额使用 Decimal，按同一原验收、同一报价版本的累计套数乘价、分位 HALF_UP 舍入差额分配。例如每套 0.333333，三次各结一套为 0.33、0.34、0.33，合计 1.00。
- 提交、会计确认与验收更正共用裁床事务锁。已占用验收不能直接改报、保存更正或作废，须先退回／反结；仍受内部锁月保护时还须办理内部反结。
- 重复请求按原操作者与原请求内容核对；结果未知时只能核对原操作结果，未执行操作被封存，不能通过新编号悄悄重发。
- 页面保留冲突草稿与报价输入，可主动刷新依据；父页面订单查询不丢草稿。实际撤权清除费用、报价凭据和复核声明，恢复授权后重新取依据；业务内容不写浏览器持久化存储。

## 复核展示与兼容性

- 草稿预览由后端按同一正式金额算法计算。外厂确认绑定本单月份、验收有效版本、数量、报价版本、币种、舍入前缀、金额及凭据文本；记录确认登记人和时间。保留旧凭据不等于自动确认新金额。
- 历史冻结版本明确标注已失效、不计入当前有效应付，同时显示当前单据状态并可返回当前版本。旧快照不改写。
- 本月待复核占用和已确认应付按币种分别汇总；加工厂和币种筛选只影响展示，不删除隐藏已选明细或缩减整月汇总。
- 复核展示与上一编制版本的数量、单价、金额及分位差额；币种改变时只并列展示，不计算跨币种差额。
- 升级前已确认应付保持原快照；旧待复核单须退回重编、预览并登记新的外厂确认。原未知保存操作仍按原内容核对，新可选字段为空时保持旧回执指纹兼容。
- 本轮无需新迁移或权限；前后端须同时更新，旧客户端未登记新确认时只能保留草稿。

## 验证清单

- 缺价、缺外厂确认凭据、验收更正草稿、超任务额度及同人复核均被拒绝。
- 多笔验收共享任务上限；同厂不同币种、不同厂同名不能混入一单。
- 两张单并发占用同一验收仅允许符合剩余额度的请求生效；重复原请求只生成一次记录。
- 验收更正与提交竞争、未知结果恢复、撤权／显式拒绝及非华康 C 请求分别验证。
- 价格修订保留旧应付金额；跨月部分结算与分位舍入守恒；受控反结保留旧版本并释放正确额度。
- 原 P2b 填数与 P4b 内部锁月回归；从既有迁移分支升级到新 head 保留原表和数据，重复 upgrade 无副作用。
- 前端费用权限隔离、保存冲突保稿、报价刷新、迟到响应、未知结果路由保护、历史只读及独立复核入口。

专用 PostgreSQL 未配置时显式跳过，不能作为已验收。真实员工、真实财务样例、生产部署、大数据量性能、多尺寸与 200% 缩放仍需业务验收；当前按厂区扫描历史并使用全局结算版本，可能产生无关订单间刷新冲突。
