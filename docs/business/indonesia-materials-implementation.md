## 不变量

- 数量采用十进制；正常＋备品占采购数，备品免费但计重量且能覆盖生产需求。
- 生产按周一至周五，运输河源至印尼工厂初始 25 自然日，整理 0 天，采购备料周期必须人工给出。
- 来料仓的供应商回复不入库，船务确认入库后才能实际齐料；正常发出仍保留已履行需求覆盖。
- 每次一客户一接收方；出货确认与下载分离，重试不能重复过账。
- 记录按厂区隔离，读写均走后端授权；新权限不自动扩张既有员工范围。
- 基础资料改动不改写旧合同需求与出货快照；变更经业务显式重算／确认并保留操作历史。

## 存储与接口

采用厂区隔离的类型化业务记录（资料、订单、供应、分配、出货、导入批次），每条保存版本；追加操作凭据保存前后变化与操作者，原文件／导出文件使用独立附件记录。写命令在厂区事务锁内校验版本、关联对象、库存余量及幂等标识。没有任意 JSON 覆盖接口。

- `GET /api/indonesia-materials/workspace?factory_id=`：当前业务记录、服务端计算的看板及操作能力。
- `POST /api/indonesia-materials/commands`：`factory_id, operation_id, action, entity_id?, expected_version, data`。
- `POST /api/indonesia-materials/imports/preview`：统一排期文件、厂区、客户、接收方；返回预览及原文件引用。
- `GET /api/indonesia-materials/shipments/{id}/export?factory_id=`：下载已确认出货的不可变模板结果，不再过账。

延期提醒、借料归还、公共备库、实际船期维护及特殊模板表现按业务框架文末遗留清单继续处理。
