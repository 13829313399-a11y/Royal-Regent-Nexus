# 华康 A、华兴 ZURU 原格式新单汇总

业务部 → 当前厂区客户订单中心 → ZURU。原 ZURU 入口书签仍跳转到华康 A 客户订单中心。
两个厂区各自独立，不能混用本机 data 或改派既有台账。

## 输入和输出

- PO：原生文字 PDF 或已核对的 XLSX，每批最多30份。
- 参照：1至10份原有 ZURU 周排期 XLSX，合计不超过35MB；不要求统一三表。
- 输出：独立 Excel，首张“新单数据”沿用旧入总排期的18列顺序；按唯一可识别原页生成“_新单”复制页。
- 接单期、客户、国家、PO、客PO、SKU（真实PO＋原Line）、完整货号、中文名、数量、内箱、外箱、箱数、走货期、验货期、备注、跟单员、美元单价与金额保持各自含义。
- 复制对应页的数据行（不含表头），在原表粘贴值。输出不带依赖其他文件行号的公式，不改原排期。

当前华康 A 原表按77902/77903等系列分页；华兴9560的接单表与Iteam表分别生成列序对应的新单页。
多个参照版本列结构相同合并为一个目标，结构冲突只提示并保留完整汇总，不猜归属。
MA、已走货、已完成、取消、库存、包材页不作为新单目标。

## 信息来源

保留本行完整SKU-SPEC和Customer PO（含前导零）、原单美元单价及原金额。
可唯一匹配的完整货号历史中文名可补入。PO备注来自当前PRODUCT REQUIREMENTS段，
不是执行指令；保留From跟单员、实际Inner和Outer。原表只有港币列时留空，美元金额在汇总页。
无可靠来源的验货期、生产状态、MA和后续人工字段留空，可直接生成后补填。
人工更正数量/美元价后重算金额，更正货号后重新匹配中文名及原页。

## 重复与修订

同PO、原行号及完整货号的历史明细列入“已有订单参考”，不重复进入可复制新单。
数量、日期、客PO差异显示原值和本单值，由业务在原表处理。只有同PO同货号而无原行号的历史
不能证明重复，显示候选提醒，继续保留新单。源PO修订版本只按原文修订记录判定。

## 合同与兼容

预览、导出、保存三个入口均传递完整参照集合；内部确定性包保留文件名和原始字节，指纹覆盖全部文件。
资料提醒不要求勾选或填写原因。权限、文件结构、身份及指纹校验仍保留。
专用新单汇总不自动同步为纸箱仓库正式排期。既有统一三表文件保留兼容读取和历史回放。

试用包固定厂区及ZURU范围，直接复用同一共享前端，包含本机台账、发送/签收和走货记录。
Windows 7 SP1 / Windows 10 x86兼容运行环境适用于32/64位配置；主机自动化测试不能替代Windows实机、原生Excel和线上部署验收。
