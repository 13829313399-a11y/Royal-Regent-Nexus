# 客户 PO 临时裁床测试线路

此入口用于独立验收数据库副本，以客户采购单生成华康 C 业务订单，再按现有流程下发裁床。正式构建的客户归属保持现有规则，华康 C 外部客户入口默认关闭。

只有构建时同时设置 `VITE_CUTTING_PO_TEST_BRIDGE=true` 和非空 `VITE_CUTTING_ACCEPTANCE_RELEASE` 才开启。界面开关不提供权限：业务订单查询、保存、下发以及裁床签收仍由原路由和后端权限校验。

## 使用步骤

1. 在裁床验收环境的“客户 PO 临时导入 → 下发裁床”进入业务订单中心，确认厂区华康 C、数据库副本及发布版本标识。
2. 点击“新建 PO 导入”，选择 INDEX、JAZWARES、MAXX 或 STROTTMAN，上传该客户实际支持格式的 PO，以及三页河源业务统一排期（ITEM表、接单表、正单评审表）。仅有 PO 时不能省略排期；空模板也须具有正常表头及分段标记。
3. 核对产品、数量、交期和异常。按原确认要求处理后保存订单台账；预览或导出本身不会替代保存。
4. 在订单台账打开对应明细，勾选“裁床部”并发送订单。
5. 前往裁床生产排期查看待接单订单，签收后继续 BOM、物料、排期等测试。

台账导入保留原文件、预览指纹、厂区、明细及发送版本。重复保存继续沿用现有去重规则。不得把华康 D 的既有订单直接改成华康 C，也不得用此入口绕过签收、BOM 或岗位授权。

## 裁床业务排期直接导入

目标为华康C生产排期工作区 `/modules/production/cutting/planning?factory=huakang-c` 的受控导入面板。使用人是有裁床读取和接单授权的岗位，保留现有厂区和部门边界；不依赖临时客户 PO 双开关，也不需要上传 PO。原文件归档到现有台账来源，原行和批次进入新来源版本；不新增数据表或自动运行迁移。

### 入口与操作

1. 展开“业务排期 Excel 导入”，下载空模板；按客户、订单号、货号、货名、数量、交期、单位七列整理 `.xlsx`，单批最多 500 行、10 MB。客户必须唯一匹配本厂配置或已有台账，编号建议使用文本以保留前导零。关键值不能为公式，交期使用 Excel 日期或 YYYY-MM-DD。
2. 读取预览，先核对“工作表核对结果”：全部工作表（含隐藏表）逐张显示已读取行数、空表或未读取原因。任何未识别的非空表都会阻止整批确认；先补齐七列表头，或从本批文件移除不导入的说明表后重新预览，不能静默跳过。表头仅在前 20 行识别，但之后出现的内容仍会检查，不能误作空表。再核对来源行、字段及每行结果；文件内重复或与已有订单冲突时整批不能确认，相同已导入来源可跳过，不覆盖旧单。
3. 填写核对说明并勾选确认，生成来源台账版本及裁床待接单。打开结果订单，按原权限签收、关联工程 BOM，明确原订单单位到目标套数的依据。
4. 可先保存无日计划的本厂／外发任务，再“发布领料任务（暂不排日计划）”，到物料库存办理领料申请、布料仓实发及裁床签收。该发布不算已排期、不建立生产基准、不记完成；有日计划的采购预排仍校验原工程需求和采购回复。调整已发布任务须填写原因。
5. 确认明确返回 409 等确定失败时，旧预览及确认勾选立即失效，保留文件和核对说明；重新读取预览、核对并勾选后才能再确认。确认超时或断网时，保持同一文件、操作编号及原参数重试，或“恢复核对原操作”，不把随后出现的 409 当成首次请求必未执行；只有恢复确定未执行并安全终止后，才清除旧预览并允许重新发起。预览、编辑原因及确认勾选本身均不写业务。原申请、实际发料和签收继续分别追溯。
