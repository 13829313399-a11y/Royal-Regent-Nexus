# 啤办模块帮助

<!-- knowledge-section:purpose -->
## 模块用途

啤办模块管理样办相关业务记录、生产任务与受控打印/展示。业务对象按后端生成的稳定标识、当前修订和权限处理；页面上的筛选或选中状态不是权限证明。

<!-- knowledge-section:workflow -->
## 正常流程

用户在授权厂区查看订单摘要，按业务流程创建或维护样办记录，再进入相应生产任务与打印环节。新增、修改、打印和状态变化必须调用现有业务 API 并通过当前权限与修订校验；AI 当前只提供解释和字段最小化只读摘要。

<!-- knowledge-section:permissions -->
## 权限与厂区

读取、编辑及其它操作分别受权限控制，并按厂区或共享部门范围重新判断。客户端传入的订单号、厂区或深链不能扩大读取范围；显式拒绝优先于普通角色授权。

<!-- knowledge-section:facts -->
## 正式事实来源

正式数量、订单状态、修订和任务结果来自本次授权 Tool 或业务页面的实时 API。演示数据、截图、测试编号和知识示例不能用于汇报生产事实；无结果时应明确说明未取得证据。
