# 合并版人员与权限工作区

> 迁移自 DESIGN.md 瘦身前版本（2026-11-22）第 15.8 节，内容逐字保留。全局规则见 [DESIGN.md](../../../DESIGN.md)，本文只约束所述模块。

三个 IAM UI 前置开关同时启用时，`IamWorkspaceLayout` 以 `.iw-studio-shell` 使用 64px 深玉顶栏；合并版保留人员与权限、权限方案、操作记录和原账号菜单。旧版六路由壳与其他业务全页不启用此例外。

人员与权限主页面使用 `.iw-permission-page` 限定样式，集中于 `src/features/identity-management/workspace/permission-studio.css`。浅瓷画布、白色工作区、青绿主操作与琥珀/蓝/紫任务分类建立层级。桌面左队列约占 36–37%，右侧人员或办理详情独立滚动；资料按字段关系分组，方案选择与权限影响按详情容器宽度并排或堆叠。底部保留原预览、确认、退回和未知结果恢复操作。

900px 及以下沿用列表/详情切换，进入详情收起页面标题和筛选条、保留返回入口；600px 及以下减少头像装饰并扩大底部触控区域。低高度窗口允许外层滚动。搜索保留 `/` 快捷键；重置通过原查询流程恢复筛选。首条记录入口只读选择，不创建待办。状态、数量、授权来源和权限影响均来自原接口与过滤条件。

导航沿用实测指示器，进场、选中、按下和加载使用短时反馈；没有常驻装饰动画。减少动态效果关闭新增动画和过渡。设计与验收记录见 `docs/frontend/IAM_UI_REFRESH.md`，实际登录与演示数据验证分别标注。
