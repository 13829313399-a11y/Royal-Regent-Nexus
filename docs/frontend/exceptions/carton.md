# 纸箱供应商协同与内部纸箱仓

> 迁移自 DESIGN.md 瘦身前版本（2026-11-22）第 15.9 节，内容逐字保留。全局规则见 [DESIGN.md](../../../DESIGN.md)，本文只约束所述模块。

内部纸箱仓库在小于 640px 的默认入口打开手机作业首页。显示当前厂区，首屏提供有权限的供应商收料、车间发料入口，并保留完整工作台入口。手机收料复用原送货单验收，普通和混合单都采用固定标题、单一表单滚动区和固定确认区；仓位使用本厂现有仓位下拉框，汇总按单位展示。手机车间发料按货号、合同、客户 PO 或仓位查可发库存，跨搜索保留勾选，单项或多项共用完整工作台的批量出库表单、校验和提交。手机将库存表重排为卡片、固定确认区，数量初始留空，可逐项选择全发。发料页支持拍摄或选取领料单照片，逐行核对合同或 PO、货号及原图。也可按连续的合同、PO 或货号片段筛选可发仓位。候选显示客户、客户 PO、纸品、仓位和匹配依据，勾选本厂可发仓位后带入同一批量发料表单。清晰的领料数量显示为可选参考，实际发料仍由仓管确认。

`/carton-supplier` 的订单页和发货与仓库反馈页共用顶部白色“协同工作台”，将订单与变更、纸品资料更正、补单接单与交期、收料核价作为同层分类，默认收起、点击展开，在同一内容面切换，避免堆叠多个警告色大面板。分类显示待办数量，读取中和读取失败分别标注，不显示为零待办；收料核价明确标注所选厂区，不把该厂数量当作全部服务厂区合计。核价只保留一个编辑器，收起、切换分类或上述两页保留本范围未提交内容，实际厂区、账号或授权改变仍清除旧上下文。缺价或异议核对与已知错误单价的“收料单价更正 / 待办”保留各自流程。Amber、Red 仅提示具体风险或错误；订单与变更展开后依次呈现当前发布单据、厂区与来源、交期和纸品的前后对照、历次回执与回应区。承诺交期、确认和异议分组，窄屏纵向排列。发货与仓库反馈每张原单提供“送货单明细”折叠入口，展开保留整单各客户来源、纸品及验收记录。更正历史在资料更正分类查看；三类订单“更新承诺交期”直接邻接“明细”。分类按钮及行内操作在窄屏换行，编号和资料可折行，沿用既有供应商表格的小屏带标签行布局。低于 640px 时多行页头随页面滚动，为明细和回应控件保留可见空间。

内部供应商确认跟进集中在工作看板“今日待办”的右侧供应商卡片，与左侧业务排期并排；供应商变更通知及其统计置顶，待核实送货单在同卡片下方。统计块沿用业务卡片的间距和字号，窄屏依次堆叠。变更明细默认收起，数量标签可展开同口径分类，读取中和失败提示在收起时仍可见。变更列表前端分页，承诺提醒沿接口分批读取。订单页和异常处理不重复展示此面板。正单、样板、杂单的“更多”共用 CartonOrderMoreMenu 和 CartonOrderMenuItem，沿用正单 176px 宽、10px 字号、统一内边距与操作颜色；共同操作保持相同顺序，菜单自动避让视口并在高度不足时滚动。内部台账复用 CartonOrderLedgerRow，供应商台账复用 CartonSupplierOrderRow；明细窗口、摘要、纸品表及汇总共用，悬停预览和点击固定规则一致。新建/修改复用 CartonOrderEditorForm 与 CartonOrderPaperEditor，沿用正单单一纵向滚动表单；同货号批量下单沿用这两组件，固定窗口标题和操作区，逐单核对可查找与翻页。追加、减单与改期复用 CartonOrderAdjustmentForm，按操作只开放必要字段。锁单/取消/删除共用 CartonOrderActionDialog，退补库存字段共用 CartonOrderStockFields；供应商接单共用窗口及 CartonSupplierAcceptanceFields，整单或逐纸品确认由业务合同决定。新采购单在供应商完整接单后进入单据列表及导出入口。合并采购单等包含的订单全部接齐，既有采购单可照常查阅。在单独、批量或订单与变更入口接齐后，对符合条件的采购单弹出按厂区下载窗口，可稍后在单据页勾选。已导出单据单独提供重新导出，显示原次数和最近时间。单据表的导出记录显示东康模板次数、最近时间和普通单据下载次数，筛选区可按东康模板是否导出筛选。不得为订单类型另建一套相同布局。各来源仍按真实权限与状态显示操作；样板、杂单沿用已有需求调整、补单和退货处理，不套用正单的合单、拆单或采购单流程。退货签收及退款保留“月结对账”子页。此局部布局不改变接单权限、厂区范围和记录状态。

纸箱内部订单台账将标题、客户范围和导入／新建入口放在同一行；紧凑交期按钮放在筛选卡片内的顶部，应用原有交期筛选。类型、客户和订单状态常显，宽度足够时“更多筛选／清空筛选”与三项常用筛选同行；展开条件单独占下一行。接单、日期及排序收在“更多筛选”，收起后仍显示非默认条件及数量。选单后显示批量栏，发送、生成采购单、追加、取消、删除和累计对账导出全部直接显示并按宽度换行。“导入 / 模板”依次提供正单、样板／杂单需求和历史订单；新订单共用工作表／列匹配、整单预览与补填窗口，支持自有 Excel 和可选参考模板，历史订单保留原入口，新建类型在新建入口选择；沿用原有权限、空态、错误反馈、表格断点与配色。

排期核对用客户按钮作为唯一客户筛选。下单状态、排期变化和排序常显，需追加和需减单与退单提醒共用「排期变化」下拉；客户交期／验货日期口径和起止日期在「日期筛选」中展开。核对历史用顶部搜索查文件名。仓库完整箱唛资料库在工具栏首行用「初稿／待确认／已确认／待分类」筛选。默认显示全部当前资料，再点已选状态可取消状态筛选。关联的历史版本可从资料详情查看。格式、客户、关联状态、订单类型和排序与清除操作对齐。来源筛选、刷新和上传在筛选区上方，窄屏允许分行。业务、供应商以及随凭证打开的局部资料列表沿用各自既有布局。
