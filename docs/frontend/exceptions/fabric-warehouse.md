# 华康 C 布料仓与半成品仓

> 全局规则见 [DESIGN.md](../../../DESIGN.md)，本文只约束所述模块。

## 工作看板

布料仓和半成品仓共用工作看板。从 768px 起待办面板双列排列，领料申请等需要横向对照字段的面板可以通栏，手机按办理顺序单列。每类显示明细数或单据数，并在同一行提供原单入口。未取到数据时显示读取状态，数量未知时保留空缺。

## 入库记录列表

布料仓「入库记录」的筛选、排序和操作按钮在宽屏同排，较窄时按可用宽度分列，最窄时一行一项。记录随整页纵向滚动，桌面表格宽度不足时可横向滚动，手机沿用卡片和分页。

## 详情弹窗

布料仓采购来源、库存批次、入库单和收发记录，以及半成品仓订单进度和收发原单，共用 `WarehouseDetailDialog.vue`。桌面居中、高度随内容调整，手机全屏。标题与关闭入口固定，正文独立滚动，业务操作在底部。概览突出物料和当前业务数量，状态及异常紧随概览，长编号和版本按单据需要展示。关掉详情时，若原入口仍在页面，焦点回到原入口；从详情办理时焦点进入办理表单。

手动与送货单／扫码入库共用入库详情。顶部显示物料、实收数量及单据状态。宽屏把批次明细与收货来源放在同一行，窄屏按批次、来源顺序单列阅读，已登记的差异通栏显示。未登记实点和差异时，在批次卡片内提示。冲销与零入库按实际记录显示，计价和登记追溯默认收起。送货单／扫码详情按同次收货的原单明细展示分仓及实点差异，部分批次冲销时区分原入库量和未冲销量。

布料仓采购来源详情首屏显示物料、供应商、采购单、剩余待收与复期，必要的数量或来源核对提示紧随概览。待收计算依据、采购原表字段和来源与变更记录默认收起。数量待核对时，有权限的人员可从提示进入「确认原欠数量」。待收量已有依据时，更正入口放在待收计算依据内。

库存批次详情突出当前库存、仓位和库存限制，正文显示缸号、卷号和来源，追溯区保留完整批次和来源记录编号。收发记录详情突出该笔业务的数量、日期、仓位与对象；调仓分别展示调出与调入，领料申请分别展示申请、已发与待发。入库流水由底部入口打开对应入库单详情，分别保留流水数量和同次收货汇总的口径。
