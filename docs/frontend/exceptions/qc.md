# QC 验货工作台局部设计

> 迁移自 DESIGN.md 瘦身前版本（2026-11-22）第 15、16、18 节及末尾 QC 段落，内容逐字保留。全局规则见 [DESIGN.md](../../../DESIGN.md)，本文只约束所述模块。

## 嵌入工作台与主题

QC 移动及窄屏弹窗的输入框、选择框、文本框与不良明细输入控件保持 16px 字号，避免聚焦时触发 iOS 自动放大；这一规则不改变验货明细表格字号或行高。

QC 嵌入工作台每次进入或重载默认使用现有浅色主题，首屏 HTML 与主题选择器也为浅色；忽略旧的深色缓存，仍允许在当前页面手动切换深色。此规则仅针对 QC，不改变 Nexus 全局主题。 验货台和审核中心的主要录入列依次为「验货结果 → 验货问题 → 改进措施 → 照片 → 备注」，Excel 导出列序沿用原规则。两页选中行、文字选中和编辑焦点使用绿色。结果、照片和三个长文本列分别为 128px、220px 和 196px。窄屏由外层页面纵向滚动，表格独立横向滚动，保留原生吸顶表头和字段定位。长文字及保存反馈在格内滚动，多张照片不能撑高单条记录。

QC 嵌入工作台使用局部 Apple Native / Liquid Glass 视觉层（`body.qc-liquid-glass`）：系统原生字体、蓝色主操作、线性导航图标、透明侧栏和工具栏、实色高对比工作表。共用顶栏保留今日通过率与本周 FAIL 数，采用横向轻量文字；零 FAIL 使用中性色，有 FAIL 才标红。高风险供应商与本周验货批次从共用顶栏移除。账号身份通过原生 details 展开 Nexus 账号信息，顶栏提供新增验货操作；宽屏单行，窄屏自然换行。数据中心分组首项为验货汇总，其后依次是不良描述库、数据导入、供应商&客户管理、供应商质量报告。现有操作和权限保持可达；业务表格维持原字段和密度，打印画布独立。深色使用同一套局部语义色；无背景模糊能力时回退实色，尊重减少动态效果。验货汇总详情在桌面保持原 540px 右侧模态检查面板，保留原有关闭与焦点机制。每次打开默认「QC验货」，仅保留「QC验货、业务资料、审核记录、修改记录」四个分组；产品及包装要求归业务资料，来源标识与版本默认折叠在修改记录内。原主表八列不变；QC原有字段保留，QC验货先显示有效商品身份，再显示验货信息、照片；删除重复照片按钮，保留缩略图。业务资料直接展示本次审核关联的有效字段，不设查看选择框或嵌套折叠，0/false与文本前导零保留，授权扩展字段展开为可读路径，原始字段与标准字段同名时注明来源。两个分组复用同一字段栅格、标题、字号和间距；采集状态与历史缺失、权限、读取失败分别说明。照片缩略图直接打开独立预览，默认轻量图；查看原图、返回预览、加载与重试位于预览层内，历史原图缺失明确提示。验货台与待审核新上传照片仅保存预览图；已有原图继续在照片查看器中可用。报告中心的图文月报 Excel 直接嵌入预览图，点击导出即生成文件。审核/修改记录采用已确认的方案 B：操作与人员、时间与详情两列结构化列表，顶部保留标题、客户/货号与状态摘要，最新置顶，点击行后详情在右列内展开，选中标签使用细下划线；审核事件与 QC 修改分开，业务采集另列。窄屏纵向排列，无横向滚动。QC备注直接显示有效审核快照内容，空备注隐藏，不以提示代替原文。详情与照片各最多一个实例；关闭照片恢复原详情位置，关闭详情取消异步请求并清理照片。业务、QC 手填与审核信息不混写。QC 嵌入工作台每次进入或重载默认使用浅色主题，首屏 HTML 与胶囊式主题开关也为浅色；主题使用紧凑图标按钮，浅色显示太阳、深色显示月亮，点击或键盘操作即可往返切换，忽略旧的深色缓存。此规则仅针对 QC，不改变 Nexus 全局主题。 客排期和验货台按「日期 → 客户 → PO」排列，日期普通横向滚动，客户 left=0、PO 偏移按客户实测宽度冻结；审核中心待审核通过普通单元格上下拖选，在原表格上方右侧统一审核确认，拖选时表格容器不显示外围焦点框，不显示复选框、逐条确认、计数条或操作提示；已审核的逐条与批量反审核保留原位，修改记录仍在客户列内；验货台不增加选择列，在普通单元格按住鼠标上下拖选，右下角仅显示统一提交审核按钮，不加入白色底栏、计数区、取消选择链接或操作提示；右侧为「验货结果 → 验货问题 → 备注 → 照片 → 改进措施」；审核中心复用完整表格，保留待审核/已审核两栏。验货台底部状态/操作条已移除，不保留空行；筛选区直接衔接表格。累计工作簿导入、撤销和验货台导出不再提供，其余页面 Excel 保持独立原有列序。行高亮以业务 ID 绑定，冻结偏移按实际列宽测量；窄屏缩短冻结列及输入框，长文本仍可滚动。审核历史采用可键盘聚焦/点击的“修改记录”入口，时间明确标注北京时间；每条真实事件默认折叠，展开显示操作人及真实差异。待审核补录使用受列宽约束的紧凑自动保存输入框，不得由输入框固有宽度撑开责任人等列；实际日期、数量、检验人员及报告业务字段可编辑，不良与测量明细用可增删行、显式保存或取消的明细表。客户要求用紧凑多行补录、走货日期用日期输入，独立于原始来源保存；合同号、客户编码、已出货数量采用同样的独立补录与自动保存；编号按文本保留前导零，已出货数量允许空值或非负数（最多四位小数），不改写原始订单快照。来源订单状态与系统时间保持只读，已审核仍锁定。待审核不再提供退回验货台按钮及其专用前端交互；已有退回状态、通知、照片和审核历史保持可读。沿用语义色区分边界、聚焦及保存失败。汇总主表、筛选和排序优先使用已保存的验货日期，旧审核缺失时使用审核快照中的排期开始日，日期列只显示日期；详情区分原计划、人工输入和来源，汇总页不再提供独立 Excel 导出，报告中心各导出保持原样；照片采用独立 Liquid Glass lightbox，只缩放图片，支持多图、适应窗口、Esc 与滚动恢复；固定 naturalWidth/naturalHeight，统一 translate/scale、指针中心滚轮及 ctrl-wheel 捏合、WebKit 原生手势捏合、拖动与两指触屏；原生捏合固定起始比例和焦点，累计 scale cubic-bezier(.4,0,.2,1) 缓起缓收曲线与 3px 轻微上移，只动画 opacity/transform；悬停或焦点进入暂停并恢复可见，均离开后继续剩余显示或渐隐时间，手动关闭 120ms，减少动态时保留阅读时间。列明真实事件的客户、PO与后端时间，非空理由才显示；批量部分失败留在操作确认框说明；待审核冻结客户格提供“反审核退回”详情按钮，刷新保留。验货台数据行统一为 64px；640px 及以下为 88px，以容纳操作格内的 PO/货号提示。保持字号，长文字及保存反馈在格内滚动；备注不自动增高，多张照片横向排列，不能撑高单条记录。

进入 QC 验货工作台且未指定子页面时，默认打开客排期；显式指定页面的链接仍进入对应页面。

## 验货台、审核中心与日期

验货台和审核中心已移除「实际验货日期」列、专用编辑及样式，PO 后直接显示出口国；历史日期和后端兼容读取保留，不清空历史输入。新审核确认时优先采用人工日期，否则采用任务捕获的计划开始日；补位不反写人工输入。汇总列表、筛选、排序和现有导出日期列读取冻结的最终日期；详情分别显示原计划范围、QC填写日期、最终日期和来源。历史无来源标记的记录保留旧值及空值；反审核重审重新决定日期并保留旧事件。侧栏分组为「工作台」，「统计中心」位于品质年报下方，页面键与权限保持。

待审核沿用验货台的「全部日期」下拉，按待审核任务的计划开始日筛选；已审核与客排期共用日期范围控件。审核中心默认及重置时显示全部日期，行验与客验各组内按计划验货日期从早到晚排列。日期筛选未选时显示「筛选日期」；弹层使用单月日历和月份切换，标题仅显示月份、按钮日期仅显示月日；完整年份保留在日期值、悬停说明和无障碍名称中。桌面客排期弹层宽 280px、日期格高 32px，审核中心弹层宽 224px、日期格高 24px，局部清除通用表格留白；触屏保持 44px 点击目标。先选开始、再选结束，同一天可选两次，反向选择自动归一。起止点和区间沿用当前主题色，底部仅「应用」，未选完整范围时禁用；移除「今天及未来」、周快捷项和文本日期输入。Esc／点击外部放弃草稿，应用后完整显示实际范围，日期按钮按内容保留宽度，不使用省略号；窄屏允许换行，重置恢复未选；默认数据范围与业务契约不变。

客排期工具栏与表格共用外观边界，吸顶显示。表头第一列的复选框全选当前筛选结果，并与各行复选框居中对齐。日期、客户、搜索靠左，条数、刷新和推送靠右。全部显示时只列总条数，筛选减少结果时显示「当前 / 总数」，勾选后显示已选条数。搜索框最大 144px，日期随内容扩展，客户框 120px。有筛选条件时显示重置，窄屏按可用宽度自然换行。桌面控件高 32px，触屏高 44px。

验货台、审核中心和验货汇总也将日期等筛选放在搜索前，有条件时显示重置。打印、批量审核等操作靠右。日常验货列表的搜索紧跟筛选入口，不良描述库的搜索与标题共用一行。

审核中心的待审核／已审核复用圆角分段控件。宽屏使用一条工具栏，日期和判定筛选紧靠搜索框左侧，窄屏按组换行。搜索框宽度上限为 144px。工具栏与表格共用外框，纯图标刷新紧挨审核操作左侧。

## 报告中心

各厂区报告中心标题下方固定显示「月内报告、年报」。两组切换共用圆角玻璃滑块，随选择平移，减少动态效果时直接定位。周期控件与上方报告类型左对齐，日期紧随周期控件。日、周、月均在日期右侧显示当前页的客户筛选，刷新在筛选行最右端，导出 Excel 在报表右下角，周报和月报在表格顶部分别提供两个和三个模板页签。日显示月日，周显示周一至周日的月日，月仅显示月份；日历内可跨年选择。年报筛选行左侧为年份与客户，右侧为重置与刷新。窄屏页签均分可用宽度，明细表可横向滚动。月内报告通过日／周／月玻璃分段控件切换，默认周报，返回时记住上次周期。报告日期筛选采用紧凑的标签与日期组合框，日、周打开单日历，月打开中文月份网格，年报列出已有年份。弹层使用 QC 主题色，触屏操作目标高 44px。日、周、月首页显示关键字段，客户质量签核首页显示月份合格率图。表头右侧可打开完整工作簿，预览顶部保留表格标识、紧凑模板页签和导出按钮，底部切换工作表。客排期的每一行独立显示浅绿色日期单元格和勾选框，同月日期范围以紧凑的两行显示；保留原字号与行距，移除单独的数据来源卡片，错误仍显示在表内。

## 控件、搜索与加载

QC 各板块的搜索框沿用审核中心的胶囊圆角、浅色柔和底和细内描边。控件尺寸及布局继续由各板块定义。

QC 宿主的厂区下拉及工作台各页面、行内表格和弹窗的单选仍使用原生 select。浏览器支持可定制原生选项时，收起状态保留原控件宽高、字号和位置，使用紧凑双箭头。展开时使用半透明圆角面板，选中项有对勾，键盘焦点和禁用项可区分。表内原有无外框样式和报告状态居中规则继续适用。不支持时沿用操作系统选择器。日期日历和手机筛选保留当前布局及应用流程，选项样式与 QC 主题协调。

QC 初始加载采用已确认的“双环回旋”：图形等比放大至 80px，外环淡紫 `#b6a2cf`、内环及中心点淡绿 `#9bc5ac`，环尾向暖白底 `#fbfaf7` 渐淡。宿主连接与嵌入页数据初始化共用视觉规格，读取完成即结束；减少动态时显示静态双环。状态文字供屏幕阅读器读取，错误信息保持可见。

## 表格与照片

QC 屏幕业务表格的表头和字段统一水平、垂直居中，表内编辑控件保持相同对齐。手动填写的表格单元格及不良／测量明细网格保留原生 input/textarea，但默认透明、无可见内框和圆角，点击即可填写，填写时仅保留光标，不显示绿色四边焦点框或阴影；QC 各板块手动输入项、表内下拉框以及表格容器和数据行遵循相同无外围描边规则，校验错误保留红色提示；下拉、选择框、表外筛选与独立表单沿用既有控件，保存、只读和审核锁定规则不变。验货台／审核中心填写后自动保存，成功静默完成，不显示“已保存”也不预留反馈空行；等待保存、保存中、失败与重试仍按实际状态显示。验货台和审核中心点击缩略图后，沿用报告中心的半透明遮罩，按当前视口等比例居中显示完整照片。点击照片及工具栏外的遮罩即可关闭，键盘可按 Esc。仅在可翻图、查看原图或重试时显示底部操作，滚轮与捏合可缩放。有编辑权限时，验货台、审核中心和移动验货的图片上方使用同款半透明工具栏，提供浏览、箭头、圆圈、撤销和重做。每画完一笔、撤销或重做时，标记自动同步到验货记录。桌面端保存失败时在预览内保留编辑并允许重试，移动验货先存手机并在联网时同步。画入新标记后清空重做历史。标记随照片缩放和移动，同步后按验货照片的查看权限共享，已审核和汇总详情只读显示。验货台与审核中心的来源列按内容在合理上下限内收紧，长文本换行并保留格内滚动；空照片列只预留上传按钮，有缩略图时再扩展。审核客户格需完整容纳选择、退回标记与修改记录。客排期、汇总、不良描述库和日／周／月报使用紧凑列宽，保持字号、冻结、固定行高与业务操作；屏幕规则不改写 Excel 或打印模板。

## QC comprehensive upgrade

QC 保持现有 Liquid Glass 与原生表格。验货台结果后为抽查数量，照片后为检验人员；验货台和审核中心不再显示实际验货日期及完成情况列，日期历史和报表兼容数据保留。完成情况由结果派生，仅 PASS 为已完成，其余为未完成，审核流程状态独立；审核恢复连续单表及一个冻结表头，行验全部在前、客验全部在后，同类型内沿用所选排序。第一条客验记录整行填充浅黄色，其余客验记录保持普通底色；不再显示独立标识行、分组标题、计数及重复表头。缺少可确认类型的记录排列在表尾，不设第三个分组标题。各组共享筛选和批量确认，客户/PO冻结。验货台检验人员、审核中心第一／第二责任人使用无常驻内框的手动文字输入，沿用静默自动保存并保留原姓名；继承的抽查数量及检验人员为普通只读文字；已填结果、问题和备注平铺显示，待审核可点击原格编辑，已审核无输入框。报告状态保留原生 select 的键盘与保存行为；支持 base-select 的浏览器中，展开选项文字与收起值居中，箭头和选中标记独立定位，不挤偏文字；其他浏览器回退原生选择器。短字段与多行填写框各自统一尺寸。验货问题、分析原因、改善措施在审核填写区相邻排列，第三方机构仅在客验最右侧，有配置名单时下拉选择，无名单时手动填写。报告入口沿用紧凑按钮。周度图文记录表与月报模板一致，在原模板区域切换，保留日期、日／周／月控件及模板按钮；客户筛选、表格和照片查看沿用月报样式，通过原周报控件返回概览，不新增跳转页面或返回按钮。图文导出直接生成预览版，不提供图片质量或原图替代选项；月报保持原模板页面及直接导出。年度保留现有页面和返回入口，底部小按钮不悬浮。所有增补字段不改变原始来源契约；旧字段隐藏不清历史。
