# 华康 A 3D 打印工作区

> 迁移自 DESIGN.md 瘦身前版本（2026-11-22）第 15.4 节，内容逐字保留。全局规则见 [DESIGN.md](../../../DESIGN.md)，本文只约束所述模块。

`src/features/three-d-printing` 以 `.tdp-theme` 限定青瓷白与深青绿的表面、按钮及动效，不改全站 token。工作区保持桌面 216px、中屏 175px 侧栏，以及 1100/700px 的机台 4/3/2 列断点；每日记录的两条工具栏、机台、表格顺序不变。一级导航指示器测量当前按钮，窄屏可手动横向滚动。主按钮复用共享 Button，busy 仅由实际请求驱动；机台状态和进度只按新鲜遥测呈现。原生弹窗和右侧机台详情保留内容至退出结束，期间可重开；图片预览关闭后返回原草稿。入场仅在首次有内容时短暂分组揭示，刷新和实时更新不重播。所有位移、扫光、旋转与退出生命周期都遵从 `prefers-reduced-motion`。
