# 公共表格转换与合并工作区

## 目标与范围

目标路由为 `/tools?factory=<id>&tool=spreadsheet-merge`，面向已登录员工。厂区沿用公共工具栏的上下文元数据规则；此工作区仅处理用户提供的表格并下载文件，不写入业务库。源码限定于 `src/features/spreadsheet-merge`、`src/api/spreadsheetMerge.ts` 和工具栏入口。保留既有转换、协同填表、改名的流程与权限。

采用先预览后导出流程：上传主表或选择系统包装模板，上传副表，指定工作表与表头行，确认字段对应、组合匹配字段和备注，预览新增/补齐/冲突/问题，再明确解决冲突并下载。名称缺失保留空白；不会把货号代作产品名称。包装模板有未完成资料时只提供明确标注的待补版。

## 设计依据

沿用 DESIGN.md 5–10、12、17 节与公共工具栏应用壳。复用 SectionPanel、Button、StatusPill 和语义色、边框、圆角 token。表格保持横向滚动、固定表头，单元格保留换行；业务字段不压缩为难辨认的小字。手机将两个来源和设置纵向排列，表格可键盘聚焦和横向滚动。页面不增加全局视觉样式与装饰主题。

## 页面结构与状态

1. 顶部说明和流程步骤，明确仅生成文件。
2. 并列主、副表来源面板：上传、工作表、表头行、样例预览和文件警告。副表允许选择普通表格或纸箱尺码表整理。
3. 字段对应表：每个副表字段选择主表列；未映射字段可明确选入备注。组合匹配键默认空，提示此时仅追加，避免自行覆盖。
4. 结果面板：输出行数、新增数、补齐格数、冲突数，逐项或显式批量保留主/副表值，源行追溯、问题、完整预览分页和下载。

默认状态显示上传入口和操作说明。读文件、合并与下载分别有处理中反馈。空表、无数据、错误和缺资料有具体文字；请求失败保留输入供重试。文件、工作表、表头、映射、匹配键或备注选择改变时立即清空旧结果与决定，并取消过期请求；离开、账号或厂区切换清空临时来源。页面内不持久保存上传数据。

## 验收

单元与交互测试覆盖表头选取、同名映射、64 MiB 限制、可复合匹配、冲突选择、参数变更清空预览、过期响应隔离和待补导出。运行现有 `test:unit` 与 `build`；浏览器由本次主任务统一验收，目标视口 320、640、1024、1280、1536、1440×900 和宽表 1920×1080。需实查上传、长名称、空状态、错误、结果、冲突和键盘焦点；未运行的视口/状态保持未验证。
