# 印尼走货明细 UI 简报

新入口 `/modules/sales-business/indonesia-shipping` 服务业务部/印尼小组，明确选择六个实际厂区之一。主要工作是延续 RR-Portal 的客户/货号/物料/采购/生产/排期/出库/走货及报关流程。现有“送印尼物料”保持独立；业务数据和原字段语义不做转换。

遵循 DESIGN.md 第 2、3、8、10、15、17 节。外层复用 Nexus 的 Button、SectionPanel、Lucide Ship、字体、背景/边框/文本 token；只添加紧凑身份与导航条：返回业务部、模块名、当前厂区、当前账号、厂区选择与重新连接。主体以 iframe 保留上游 React/Ant Design 的原始布局、密度、筛选、弹窗、编辑器和导出动作，其 CSS 不进入全局。该样式隔离是保留完整原前端的明确局部例外。

集团选择显示“请选择厂区”；连接时显示状态文本；未配置/无权/服务异常显示具体错误与重新连接；成功后才挂载工作区。账号、授权或厂区变化立即卸载旧内容，异步旧响应不能重开它。六厂均已配置独立资料库，新厂显示真实空表，不添加演示订单。父页提供标题、账号、厂区、返回和独立打开入口，不用技术实现解释占据业务操作区域。接入模式移除旧账号管理菜单、顶部链接与页面，直接进入旧地址返回有权业务首页；数据库维护入口仅按 Nexus 的独立维护权限显示。账号管理、人员任职和厂区授权通过现有 Nexus 功能完成。

外壳支持320px起宽度、header换行与可访问select；大表保留原应用的横向滚动，窄屏显示电脑操作建议。键盘可达返回/厂区/重连，select有显式标签与焦点轮廓，iframe有可访问名称。无新增装饰动画。

验收计划：业务部卡片→工作区；group禁止回退；有权空表/实际测试资料；无权限与服务关闭；厂区及账号切换；原货号图片、Excel导入、RRI/RRM报关模板下载、管理员页；1366×768、1440×900及设计规范规定窄屏/断点。使用 Chrome DevTools MCP 检查真实URL、控制台/网络、键盘、溢出和截图。当前工具缺失时此项标记未验证；Vue/React构建、自动化行为测试与真实API端到端检查独立报告，不代替视觉验收。
