## 为什么不能直接换回旧代码

裸旧代码只检查最终消息里的来源。V3 曾暴露、但后续快照裁掉的来源保存在 execution 的并集中；旧代码不读取它，撤权后仍可返回合成的私有回答和成果。完整旧源码的实际读取已复现该缺陷。全关助手返回503可以阻止读取，但不能证明开启状态下安全。

兼容补丁只改三个文件：

- `service.py` 在投影消息前合并持久来源，再调用原生 `visibility.allowed`；正文、历史、搜索、成果和导出沿用同一可见性判断。
- 新增 `rollback_compat.py`，在当前数据库连接读取 V3 依赖，不需要新 ORM。缺表、缺行、无效依赖或未知协议/来源均隐藏内容。旧 v1/v2 不依赖新表，原接收和 canonical hash 算法保持不变。
- 旧 `config.py` 的工具轮数校验允许0，保留旧默认5和上界16。旧 runtime 已支持0；这使现有零轮数限制不必提高。QA 配置未改。
