将本文件和同目录三个文档一起交给 Codex。建议存入项目 `docs/assistant/`，再复制下面提示词。文档是方案，不代表代码已经实现。

---

你现在需要在 `D:\RR\royal-regent-nexus` 为 **Royal-Regent-Nexus** 实际开发一个新的通用 AI 助手，名称是 **曜灵 · Nexus AI**。请完成实现、测试、视觉验收、独立复审、问题修复和回归，不要停在计划、架构图或静态 mock。

首先读取项目当前 `AGENTS.md`、`PROJECT_MEMORY.md`，再读取本目录：

1. `01_YAOLING_CODEX_SPEC.md`：产品、华丽视觉与交互、前后端契约、能力与部署规格。
2. `02_CODE_AUDIT.md`：已核实代码事实、真实接入点、业务口径及尚未验证项。
3. `03_ACCEPTANCE_CASES.md`：具体测试输入、预期行为与验收记录要求。

本次新建通用助手的明确要求替代旧资料中的“不要恢复通用 AI”方向。但旧 AI 退役迁移、旧数据删除历史及已有业务权限保持不变；不得回滚旧迁移、恢复旧治理平台或冒充找回旧会话。

## 必须实现的体验

曜灵是面向所有合格登录账号的助手，普通员工、只读用户、管理员、供应商均可自由聊天。自由问答不限定在厂内业务，不能机械限制字数、强制 JSON、关闭思考或每个问题都调用工具。

助手在应用侧边以“曜核”显隐，可拖到左/右侧，展开为华丽侧舱，也可进入大尺寸专注阅读态。使用深翡翠、香槟金、少量折射光、白色阅读区、流畅进出场和细腻按钮反馈。不是普通灰色抽屉换标题，也不是全屏霓虹。

助手需要知道当前模块的用途、字段、状态和步骤，支持“讲解本页”“指给我看”和准确定位。帮助内容绑定真实代码与语义条目；没有依据就说明未知，不能伪装读取了实际订单、价格或生产数据。

当前接入千问，但使用独立助手 provider 和配置，不复用 OCR/报价候选识别提示词。模型、地域、思考、图片、联网和工具能力以真实接口与验证结果为准。前台名字始终叫曜灵；关于页如实披露实际模型服务。

## 执行纪律

- 先检查当下 HEAD、工作区差异、入口文件和迁移图，不把文档中的审查基线当永远不变。审查时已有 `PROJECT_MEMORY.md` 修改和 `test-artifacts/`，不得覆盖。
- 按需深入读取模块与依赖实现，以精确理解优先；不要机械限制扫描文件数量。不要把无关敏感数据、真实密钥和整库内容倒进日志或 prompt。
- 不更换业务技术栈，不重做报价/排产算法，不改变设备控制、通知责任与身份权限。
- 新助手从 `src/App.vue` 根层接入；必须覆盖普通页和已授权 fullPage 页面，不能只挂普通侧栏。
- 同一个账号的正常身份刷新不应中断长回答；注销、账号更换和任职周期变化必须正确清理。
- 会话、消息、附件、run 都按当前用户与任职周期隔离；前端路由可见不代表有权读后台数据。
- 不擅自读取/输出真实 Key，不向公司付费模型自动探测，不迁移真实数据库，不部署、不提交、不推送、不切换分支。
- 测试先读 fixture，使用隔离数据库和合成数据。项目启动会执行初始化，生产镜像启动还会执行迁移，不能拿真实库做冒烟测试。

## 阶段与完成标准

按主规格 P0–P5 推进。每阶段产出可检查实现与证据；视觉和交互是正式验收条件，不留到“功能完成以后再说”。

实现真实流式输出、停止、幂等重试、历史、删除、完整导出、状态恢复、帮助引用与真实定位。保留已生成内容，不让断线自动重复收费。不要放未实现的联网、语音、图片或工具按钮。

缺少真实模型配置时，完成模拟协议、错误路径与全部可本地实施的能力，同时报告“真实模型连接待验证”。不要因为缺 Key 停下全部开发，也不要把模拟测试写成实测联通。

所有现有/新增命令必须存在且真实运行。当前有效前端命令包括 `npm run typecheck:app`、`npm run typecheck:test`、`npm run test:unit`、`npm run build`；当前没有可以直接假设存在的 lint/E2E 脚本。

完成一轮后，以独立复审角色检查身份与上下文、流式生命周期、数据库与回退、知识准确性、视觉与键盘交互；修复问题并重复相关测试。有并行子代理时限定清晰文件边界与审查职责，不为每个小任务建立多层代理。

将证据保存到新的 `test-artifacts/assistant/<run-id>/`。最终报告准确列出：修改文件、已实现功能、真实模型状态、测试命令与结果、截图、复审与修复记录、未验证项、开启及回退步骤。只有实际完成并验证的项目才能标记通过。

`PROJECT_MEMORY.md` 在真实落地后原位更新，区分新助手与旧退役系统，保留既有未提交改动；不能在尚未实现时写成“已经上线”。
