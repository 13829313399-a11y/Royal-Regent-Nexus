## 私有反馈与消息操作

`GET/PUT /api/assistant/runs/{run_id}/feedback` 复用当前登录、run 所属者、任职周期及完整来源并集的可见性检查。仅终态可保存，来源只能选择本轮服务器登记且当前可见的来源。类别为事实错误、没回答问题、来源问题、体验问题；说明最多 2000 字，来源最多 32 项。反馈不执行模型调用、不修改原回答，也不产生业务写入。

保存使用 `base_revision` 和冻结的 `client_request_id`。相同请求重传返回同一版本；同编号不同内容或版本冲突返回 409。保存结果不明时，客户端锁定原请求和草稿，用户可以读取核对或明确重传同一请求。冲突保留草稿，替换版本须经用户选择。关闭表单保留草稿；身份、任职周期或来源失效会清除私有内容，迟到结果不能恢复它。删除会话级联删除关联记录。

消息常用操作为复制、继续追问、更多。编辑重问及重新生成位于各自消息菜单，只准备未发送草稿；遇到已有草稿沿用原确认流程。成果、检查清单、表格、图表、导出及反馈复用既有菜单、token 和组件，没有新增依赖。

## 订阅确认与耗时

V3 订阅可带独立 `subscriber_id`。服务器分别保存 after_seq、delivered_seq 和 applied_seq，确认不得超出该订阅发出范围，重复确认只前进。客户端只确认实际应用的事件；缺口后的完整快照不冒充事件已应用。缺失遥测保持未知，GET 200 不等于恢复成功。确认失败不阻塞渲染、不重发生成 POST 或触发付费重试。

分别采集首事件、首模型增量（含思考）、首段正文和运行时长。取消请求、运行终态和上游迭代器关闭是独立时点；真实关闭后才记录取消至关闭时长，不能据此断言物理设备或外部线程已停止。停止按钮立即显示“正在停止”，服务器返回后才展示最终状态。

## 管理员诊断边界

`GET /api/assistant/diagnostics/operations?days=1..31` 及 `/diagnostics/runs/{run_id}` 复用原生集团 `system:access_manage` 权限。仅返回聚合或明确选取的运行元数据、步骤及 provider request ID、枚举错误、数字用量和反馈类别；不返回员工身份、会话编号、消息、反馈说明、来源标题/摘录、地址、路径或凭据。管理员不会因此获得他人私有反馈 GET 权限。本人 `/runs/{run_id}/diagnostics` 仍校验本人和来源授权。

统计按保留数据和窗口区分已采集、未采集、进行中及未完成汇总。引用定位比例只表示引用绑定；业务查询比例只表示取得结果，均不是语义支持率或答案可信度。文件解析计数是窗口内创建文件的当前状态，不冒充历史失败率。p50 至少 20 个样本，p95 至少 100 个；未达阈值返回 null，样本数及观测范围单列。

SQLite 使用一致只读快照及 progress handler；表结构检查复用该快照的连接，避免另一读连接与等待提交的写事务互相阻塞。PostgreSQL 使用 REPEATABLE READ、READ ONLY 和逐语句剩余时限。默认 `ASSISTANT_OPERATIONS_QUERY_TIMEOUT_MS=1500`，允许 100..10000；超时返回 504，不返回部分计数或假零，退出后清理连接回调及事务。真实隔离 PostgreSQL 17.11 已验证原生读取事务：另一连接提交后当前快照仍保持原值；100ms测试上限下 pg_sleep 被取消并返回504，随后读取成功、会话时限恢复。合成字段在 finally 中复原，419表及资产哈希未变。该补验没有重验管理员身份边界或浏览器页面。
