# 设计决策与业务待确认

- 新领域：`SprayOps*` / `spray_ops_*` / `/api/spray-operations` / `spray_ops:*`，不复用旧模块代码或自动导入旧表。
- 处理工厂只允许 `huaxing`、`huadeng`、`huakang-a`、`huakang-b`。委托方和来源工厂独立存储，缺省/集团/其他厂不得回退华兴。
- 所有业务外键绑定 `(factory_id, id)`，所有命令携带 `operation_id` 和 `expected_version`。每厂持久协调行先加写锁，随后处理幂等、期间、实体与资源校验；同一事务落业务、账本、审计和回执。
- 库存以物理批次状态及移动记录表达，计划预留独立于实际耗用。工艺按有向无环图的完成步骤集合推进，不能靠固定工序序号绕过前置条件。
- 精度采用 Decimal；单价可为空，未知值不得补零。数量为正数，退货/贷项用方向表达。员工产量与产品产量分别计算。
- 工资、商业单价、工序产值和实际材料成本是独立口径。默认没有批准规则；历史 Excel 计算可复现，但不能自行生效。
- 导入先按文件签名识别格式，再按来源配置解析。源文件哈希、坐标、原始值、公式、缓存和用户决策保留；公式错误不转零、负数不自动入账。
- 开关默认关闭。开发采用独立数据库和端口，现有本地服务与业务数据库保持原状。

## 待业务确认（独立功能可继续开发）

工资规则与补贴/保底口径；工序价格与交收价格；汇率及折算方向；SKU 单位换算；班次/日历/产能；工具共享与准备有效期；收货/报废/退货审批；费用归集；期初截止日；导入主事实来源；正式岗位授权；周转物收费；月结币种/税与请求书格式。

任何确认须有生效版本、确认人、时间与来源证据，禁止用演示默认值代替。

## 实现差异与验收边界

- 导入采用签名解析与人工类型化逐单映射。来源表的复杂续行、横向日期矩阵和跨表业务匹配尚未自动化；S04/S06以参考或期初方式处理。12个Profile存在不等于每张原表完成业务接管。
- 日报拆分生产、人员与日工资工作表以避免多人重复产量；9类导出已有中文表头、单位、金额、冻结下载、A4横向/重复表头。尚未按S02/S08等原表逐文件完成原样模板金样，也未验证真实打印分页。
- 工厂事务协调行优先保证数量、资源和金额守恒；目前实测是SQLite。PostgreSQL锁竞争与生产吞吐仍须隔离环境验证。
- 原币种成本/工资/产值分别冻结，缺项不补零；跨币种统一经营利润未实现。软件覆盖度只能检查已登记证据，不能证明现场业务无漏报。
- 多容量资源的同时任务尚未分配独立时间轴子泳道，当前可通过计划表查看。完整200%缩放、屏幕阅读器、所有失败状态和触屏等价流程尚未验收。
- 主代理执行了与编写分开的审查及失败路径回归；未启用子代理或声称经过外部独立审计。具体发现与复测见ACCEPTANCE。
