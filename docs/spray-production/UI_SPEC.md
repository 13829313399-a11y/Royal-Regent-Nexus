# 喷油工作区界面合同

入口 `/modules/production/spray-production`。遵循仓库 `DESIGN.md`，全页独立壳只作用于本模块；前端开关关闭时保留生产部占位卡，不伪造实时数字。

## 空间与任务

64px顶栏（执行工厂、业务日期、订单检索、返回生产部、账号）；72px导航。七个工作区分别是总览、计划、执行、胶件交收、油漆采购、经营月结、基础资料，另有导入与操作记录工具入口。主按钮、空状态、错误、只读/授权及加载状态均使用真实请求。

排期资源列188px、资源行72px，需求池264px可在240–320px调整或折叠为46px。时间轴支持滚动、缩放、5/14天、手工表单与拖动提出调整、预览比较、撤销、发布；已经开工/暂停占用不能当成空闲。条件计划展示预计条件，只预留能力，不能报工直到匹配实际来料。

订单追踪复用同一组件：≥1680px使用392px侧栏，其余为模态抽屉；显示需求、实收、期初、库存、价格授权、工序实绩和关联入口。关联入口按真实订单关系筛选记录，合并单据保留完整内容。

执行页分任务、日报、质量；日报独立正班/加班及好/待判/废数量，合并任务逐单分摊；实名工时独立于产品数量。草稿可修改，确认后以冲销保留原记录。批量粘贴先预览，不能自动给人算工资。

油漆页分采购、批次、领退耗、节约；工资显示试算/正式状态及每人分摊；月结选单只用截止月份已验收未结量；费用、材料未知继续显示待核对。外币不混加为利润。

## 上下文与交互

请求隔离键包含用户、执行工厂、授权版本及权限快照；读请求代次及写入栅栏阻止迟到响应覆盖；同厂相同授权对象刷新不销毁草稿。撤权清除敏感缓存和待重试内容。网络未知结果保持原操作编号，通过本人回执核对。

切厂或离开前处理未保存内容，取消切换时厂区/URL/草稿保持原状。原因与放弃提示在页面内完成；原生 dialog 管理键盘焦点，关闭恢复触发元素。库存版本冲突保留填写，材料表单提供刷新批次后再次核对入口。

小于1024px默认任务列表；390px保留工厂和日期、底部横向导航。宽度1920/1440/1366/1024/768/390已检查页面无横向溢出；宽表在表格容器内滚动。
