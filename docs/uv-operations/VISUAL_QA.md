## 概念与实现对照

| 项目 | 概念 | 实际实现与理由 |
|---|---|---|
| 主布局 | 深青导航、浅雾背景、横向机台行、任务侧栏 | 保留层级、间距、边界及横向机台；宽屏侧栏，手机全宽详情 |
| 品牌 | 概念示意logo | 使用项目既有动态品牌SVG，动画某些帧显示中文；不冒用生成商标 |
| 产品/机器图片 | 示意图片 | 使用统一图标；存在已上传预览文件时才显示真实预览 |
| 运行进度 | 示例进度条 | 未支持的进度显示未知，条纹空轨，不生成随机百分比 |
| 数据密度 | 三机及核数同屏 | 现场突出机台，核数为独立可操作页面；首屏计数可直达待核对运行/品质 |
| 业务数值 | 概念示例 | 合成模式醒目标示，产量以核数为准，成本缺项和过期状态保留 |

## 独立复核与修正

独立只读复核原5张代表截图，静态可观察部分为：层级20/25、品牌13/15、诚实数据呈现8/10。业务可操作性25、交互动效15、手机键盘10不能仅凭截图评分，没有把这些分数补满或拼成85分结论。

根据复核已修正：任务产值显式币种/精简无意义尾零；当前班次记录数与全部分页数区分；手机成功提示进入文档流避免盖住标题；现场首屏待匹配/待检计数直接链接真实待办。修正后的截图已重拍对应页面。字体和动画沿用现有系统，遵守减少动态效果设置。

动态证据包括真实核数提交、异步导出完成、权限失效清空、详情焦点返回、表单排程冲突，以及组件中的返工绑定批次选择、网络失败原草稿/回执语义。完整拖动端到端已于2026-09-29补齐；实体触控、屏幕阅读器和长任务动画帧分析仍未覆盖。

**不把截图工程自检冒称最终≥85分签字验收。** 实际业务人员仍需按原文六维度对完整操作流程评分，且任何严重权限/假数据/闭环问题不能由总分抵消。现场接入和生产发布另见 SITE_READINESS。
