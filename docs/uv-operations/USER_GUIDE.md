# 操作指南

## 从空资料开始

1. 管理员显式授权 `huakang-a / production` 的 UV 权限。在基础设置登记机台、产品、治具和工艺版本。治具槽位必须对应真实物理位置；未知机台参数留空。
2. 上传工艺预览图和生产文件；确认文件版本、首件或明确豁免依据。文件只能下载，系统不会发送到打印机。
3. 任务与排程中新建需求，再按稳定 ID 选择工艺、文件及价格/工资版本创建任务。任务保留创建时快照。原先缺失的价格/工资可有原因补齐，既有快照不能覆盖。
4. 选择任务、机台和时间区间预览冲突；也可拖动计划生成预览。确认后才写入排程。固定、已执行或已取消任务不能随意重排。拆批仍属于原任务的顺序排程，本版不支持同一任务的分批并行多机排程。
5. 班次与品质中创建实际班次、登记参与人及起止区间，录入核数。加工件数必须等于良品+返工+报废+待检；中间遍的合格件不会提前计作成品。多行可粘贴预览，再逐行核准。
6. 对待检件登记品质结果。返工使用绑定原批次的子任务，仅消耗原批次返工余额；完成数量合并到实体结果，尝试次数独立统计。未加工且无已确认 Run 的批次可拆分/合并，并在任务档案查看流转来源。
7. 发起部分交接，选择有权接收人员；签收、拒收、退回分别记录，不重复生成产量。未签收部分可有原因取消，日期不能借用未来余额。
8. 材料页面按 SKU/批号/库位收料、移库、消耗、退回。墨量遥测仅供对照；确认耗用才进正式成本。库存不足会拒绝，不允许负余额。
9. 效益核算中登记费用、核准工资、检查缺项。参与人重叠人时按实际区间分配。工资冻结后不能追加参与人或覆盖来源核数。不同币种分列；缺成本期间利润为空，不补成 0。
10. 清理未匹配运行、待检和未关班次后封账。封账后的迟到采集进入差异待办。需要调整时由有权限人员有原因重开，处理差异再重新封存，历史快照仍保留。

## 运行证据核对

现场只读采集与人工核数分开。选择待关联运行，逐项选择任务和该任务的有效批次、工序遍次、物理槽位、整板/尾板件数以及分摊份额。拼版同一遍使用同一治具，槽位不可交叉，份额总和 1。8 板×12槽+5尾件仅建议 101 件，最终产量仍需人工确认。一个 Run 的公共成本只登记一次再分摊。

代理是否在线、日志是否新鲜、设备是否运行是不同状态。未配置、过期、离线及未知进度有独立提示，不能据此判定实际机器已停机或打印成功。

## 导入、导出与错误恢复

选择明确模板并下载表头，关联对象使用稳定 ID；如列名不同，用“模板字段=原表头”显式映射。确认单位后生成预览；可选空值采用模板默认，必填空值显示行错误。确认无误后整批提交。同文件/模板/原始行/映射重复导入返回既有结果，不重复记账。大预览可保存页面 job 链接恢复。

导出选择日期范围或明确 ID，创建后可离开页面；完成后核对记录数再下载。页面只加载当前页，导出覆盖完整数据库范围。重试 503 或网络未知结果沿用原操作；409 表示数据已改变，需要刷新依据并核对草稿，不会静默覆盖他人记录。
