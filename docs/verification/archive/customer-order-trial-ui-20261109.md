# 各厂区订单排期独立试用界面

固定当前试用包的厂区，以客户、原始 PO、现有排期、来单日期为导入上下文。沿用主系统的 PageHeader、SectionPanel、StatusPill、Button、字体和全局语义颜色；主要任务是解析核对后生成 Excel 副本。用户确认包含真实本机订单台账、部门发送与签收、走货和撤销。所有记录独立保存在本机，明确不通知线上员工、不更新正式仓库。

界面分为“订单导入”“订单台账与走货”“各客排期”“本机部门收件”“排期文件历史”。复用原 CustomerOrderLedger/CustomerOrderSchedule/历史迁入/360整理与Casdon工具，由本机配置能力控制显示；默认正式系统行为不变。导入页面依次展示输入文件、明细和异常核对、保存及生成两个独立操作。宽表格在自己的区域滚动；人工补录使用服务端返回的字段名称和输入类型，阻断项及确认原因始终可见。单价明细、来源文件、字段来源和未识别提醒保留在每行详情中。

默认状态要求先选客户；配置加载失败提供重试。文件请求、生成和历史下载有明确进度；相同页面不并发提交文件任务。失败信息保持可见，超时提醒先核对历史，重试必须由用户点击。修改客户、文件、日期或核对值会使旧预览或生成结果失效；晚到响应不得覆盖新上下文。空历史和历史读取失败分别展示。

复用原预览数据类型，保留 can_skip/can_edit、blocked/confirmation、人工更正、4–500字原因和指纹校验；未知状态不得自动当作已通过。不在浏览器分配业务编号、换算价格或重算订单金额。

验证使用组件/控制逻辑测试、独立类型检查、独立 Vite 构建和 first-party source allowlist。预期桌面 1440/1920 与窄屏 390 能完成操作，但当前没有 Chrome DevTools MCP，实际浏览器布局、焦点和 Windows 下载行为均未验证。
