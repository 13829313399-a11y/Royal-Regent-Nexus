# 华康 B JP 修订数量月单验证（2026-11-25）

## 现象与修复

反馈原件的表头为 `Revised Qty (Pcs)`，原月单规则仅接受普通 `Qty`；Foxmail 纯文本同时包含空小计单元格和单元格内空行。结果是上传 EML 与粘贴正文均提示没有找到订单表格。

源码提交：`04fe549b3df0c5c8013c04ec21bd63e50b239fd1`。

- VSK 月单接受明确的修订数量表头；唯一修订数量优先于旧数量，空修订值不回填旧值。
- 小计/总计不作为明细数量；重复修订数量列仍不擅自选取。
- Foxmail 竖向分隔表保留空单元格和多行文本的位置，残缺行不重新拼接。
- 当前邮件中的多个产品表全部读取，引用历史保持隔离。原有资料缺项只提醒、合同 TBA、44 列导出规则保留。

本轮未改前端交互，独立包重新构建仓库现有 JP 前端；没有将私有 EML、参照原件或密钥提交 Git。
