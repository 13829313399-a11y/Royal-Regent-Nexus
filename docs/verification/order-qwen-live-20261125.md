# 千问订单真实样本测试（2026-11-25）

## 结论与范围

专用 Qwen3-VL-Plus 接口已连通，但本轮未证明其比现有客户解析器整体更准确。继续采用原规则生成业务值，AI 仅展示原件候选与差异；没有把错误候选写入订单或排期，没有启用服务器，没有重新交付含共享密钥的试用包。

这次确认的是“创建密钥并测试，上限 10 元”。用户提供的 9 份原始文件覆盖 6 个客户、3 个厂区及 PDF、XLS、XLSX。测试不是随机抽样，也不是全客户验收，不能用通过来源校验的比例代替准确率。原生解析失败后的 AI 补救、JP 邮件 AI、客户未支持格式扩展仍未完成。

## 实施与复核

计划：私有保存凭据 → 对照原件及既有解析结果 → 小批真实请求与保守费用记账 → 根据错误收紧返回协议 → 定向测试、独立复核 → 同步源码与记录。保留既有厂区权限、输入指纹和排期写入规则。

- 私有凭据在本机 `~/.config/royal-regent/order-ai/`，目录权限 700、文件 600；不提交密钥、下载的凭据 CSV、原单、响应全文或页图。
- 版本 `order-evidence-v2` 区分 SKU/条码、PO/供应商账户、原币/计价单位及真实订购子行/混装配比。原生证据支持短 ID，减少重复文本；返回后仍统一为来源和引用对象。
- 短引用只能指向实际存在的单元格或 PDF 文本行。页图仍要求 quote，仍标记 `text_verified=false`。原生 quote 本身必须包含候选值，不能引用同一行的另一个数字。
- 旧缓存与新版本隔离。结构错误、来源不存在、数字片段、超时等均保留原识别结果，不产生新的业务阻断。
- 独立复核纠正了混装说明歧义：有独立 ORDER QTY 的子商品保留，ASSORTMENT/COMPONENTS 每箱配比不另建订单。

| 华登 / Casdon | PDF，3 条商品 | 原解析正确区分商品和备注。AI 首轮把两条版本/货柜说明当成商品；收紧规则后为 3 条，但跨行引用、Commodity Code 误当条码等问题仍存在。 |
| 华登 / Casdon | XLSX，2 条商品及费用 | 原解析识别商品和独立费用。AI 曾把供应商账户当 PO，并产生数量错误；未采用。费用与商品分开计数，不能用总行数直接比较。 |
| 华登 / Goliath | PDF，8 条 | AI 的货号、数量、美元单价/金额可与文字核对，但捏造了 Each 单位。原解析保留 8 条；另发现其未读取 CRD 缩写、改用验货期推算，此业务规则差异未在本轮修改或验收。 |
| 华登 / Jakks | 取消 PDF，1 条及组件说明 | AI 一轮通过文字校验，但把 CA 箱单位配给商品数量、把 Customer Item No. 当 Reference。证明“原文有这个值”不代表字段归属正确。取消单仍由原客户规则修改已有单，不由 AI 新增或取消。 |
| 华兴 / Dickie | 3 页扫描 PDF，1 条 | AI 能读出数量及 HKD 单价，但品名/货号混淆，并返回额外字段或虚构来源坐标，未采用。 |
| 华兴 / 彩星 | 8 页 PDF | 两轮请求均超过测试等待时间，未得到完整输出，不能判断本文件 AI 准确率。原客户规则仍独立工作。 |

真实调用共 24 次：首轮 8 次；v2 9 次；有限思考实验 3 次；聚焦核心字段实验 4 次。21 次收到可解析模型响应、3 次超时。按各轮当时的严格校验，4 次通过结构/来源校验、17 次被拒绝；其中 Jakks 通过来源校验仍有语义错误。这些是协议与观察统计，不是准确率。

有限思考与聚焦实验只在本机测试脚本中进行，没有进入生产配置。当前提交仍采用非思考 JSON 模式；按官方说明，Qwen3-VL-Plus 的结构化 JSON 输出只支持非思考模式。增加思考没有解决本轮的字段归属与证据坐标问题。[阿里云结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)、[视觉理解](https://help.aliyun.com/zh/model-studio/vision/)

## 费用与时间

24 次调用在串行测试脚本内执行，每次发出前预留 1.20 元，余额不足则不发起。该预留按北京最高阶梯、最大输入及本轮最大输出/思考预算保守计算。成功响应按 usage 与标价回算；超时没有拿到 usage，继续保留全额预留，没有当作免费。

- 有 usage 的 21 次，按当日标价估算合计 **0.390649 元**。
- 3 次超时各预留 1.20 元，合计 **3.60 元**。
- 已知估算加未确认预留合计 **3.990649 元 < 10 元**；这不是账单实扣额，未假定免费额度或缓存优惠。
- 正常调用约 8.9–58.7 秒；直接 HTTP 测试中的超时耗时可超过 socket timeout，因此生产仍保留已有总时限子进程。默认每文件 25 秒、每批 75 秒可能只完成一部分；本轮直连测试使用 60 秒等待，不代表默认配置全部成功。

北京非思考 Qwen3-VL-Plus 标价按输入长度阶梯为每百万 token 输入/输出 1/10、1.5/15、3/30 元；思考 token 按输出计费。用量明细、文件 SHA-256、原始响应、页图与对照结果仅留本机私有测试目录。[阿里云模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)
