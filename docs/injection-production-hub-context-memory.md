## 已实现业务交互

- 当前任务锁定，不允许移动。
- 后续任务可以发起跨机台调整，但必须二次确认；正式数据由后端校验并保存新 revision。
- 资格校验先执行吨位、尺寸、厚度、开模、顶出、射胶量、机械手、抽芯、绞牙、材料/螺杆和透明专机等硬约束；关键主数据缺失时明确判定为“资料不全”，不伪造合格。
- 4A/10A 缺失换模规则会显式提示，不用猜测值代替；换模换色、颜色路径、日历停机和交期缓冲均使用明确配置。
- 待排订单选择后展示合资格候选机台、评分分解、理由和风险提示。
- 选择候选机台后必须二次确认，确认后才从待排池生成草案任务。
- 移动或分配后只重算受影响机台；正式草案由服务端检查基础 revision，冲突返回 409。
- 发布会生成当前厂区不可变版本；回滚不会改写历史版本，而是创建一个新的草案 revision。
- 本地优化器先模拟约束、排序、排程和指标，再由用户决定是否应用；高级后端优化器仍不在本阶段范围。
- 页面明确标识“正式后端”“Mock 快照”或独立空态，不把演示数据冒充正式计划。
- 华兴与华康 B 独立切换；其他厂区显示独立空态，不回退或泄露 Mock 数据。

## 后端合同与剩余边界

当前后端合同保证：

1. 所有查询、写入、外键和权限检查均带服务端厂区边界。
2. 当前任务锁定、移动资格校验和 revision 乐观并发控制。
3. 只读预览不创建正式计划，确认后才写主数据与 r1 草案。
4. 发布版本不可变，回滚生成新 revision，审计事件不可更新或删除。
5. 新权限为 `injection_scheduling:read|import|edit|publish|rollback`，不复用旧权限族。
6. Alembic 位于 `20260728_0039`；从 `0038` 启动会被守卫拒绝，必须先升级。

- 生产环境迁移、部署与业务用户现场验收。
