# 大陆发票离线工具源码

这里保存既有独立 React/Vite 离线工具的源码，包括兴信、华康 A/B/D、华兴、华登的解析、发票、面单和追溯逻辑，以及原界面和独立 codex 版入口。它没有接入 Royal Regent Nexus 主站路由、权限或数据库；提交这些源码不代表线上已启用全部厂区。

## 源码与私有资料边界

- `src/` 保留原工程全部 109 个源文件。客户映射、模板工作表选择器、产品关系和计算规则属于程序配置；历史样票的具体交易示例已从注释和固定提示中省略。
- `scripts/` 仅保留构建、合成回归和独立 OOXML 检查依赖。真实原票的逐票断言、一次性修票脚本及 `.tmp` 脚本不在此目录。
- `private-assets.json` 只列资产路径，不含模板内容。`public/`、原票、输出、备份、报告、`dist*`、依赖和缓存均不提交。原工程中的真实演示工作簿也不提交。
- 原工具内置的业务文件解密约定仅用于本机上传文件，不是服务器或账户凭据；保留既有逻辑，不引入线上密钥。

## 本机准备与运行

使用支持 Vite 7 的 Node.js，按本目录原有锁文件安装依赖，不升级版本：

```sh
npm ci
npm run dev
```

本机自行准备获授权的私有模板，按 `private-assets.json` 的 `required` 路径安装到本目录 `public/`。可选 `optional_demo` 是旧界面演示按钮使用的私有工作簿；缺少它们时不要使用“现有资料演示”。不要将真实原票或模板粘贴进源码或提交到 Git。

```sh
npm run check:assets
npm run typecheck
npm test -- --configLoader runner
npm run build
npm run build:offline
npm run build:codex
```

两项单文件构建沿用原脚本，构建前会明确检查必需模板。缺少模板时停止并列出路径。离线构建会把本机 `public/` 内的工作簿内嵌进 HTML；这些生成文件包含私有资料，只能按业务授权本机使用，不作为源码或公共发布物。普通 Vite 构建也会复制本机 `public/`，其产物同样不应公开。

## 验证范围

纯函数、合成工作簿和模拟界面测试可用于源码回归。部分合成导出/格式测试仍需要本机私有空模板；没有模板时应明确说明未运行，不把缺样本的提前返回算作通过。真实原票回归段已从提交版本移除，不需要准备原票即可运行保留的测试。

本轮整理不重做原生 Excel/WPS 打开、套打位置、全部原票金额或浏览器视觉验收，也不生成可公开分发的离线包。独立离线源码与主站在线发票集成分别维护；不能假定另一处的后续修复已经同步到这里。
