# 华康B 3D打印边缘代理

本代理留在能访问打印机局域网的 Windows 电脑上。它只主动连接 Nexus 云端：

- 打印机状态：局域网 MQTT → 本代理 → 云端 HTTPS
- 管理员暂停/恢复：云端待执行指令 → 本代理轮询 → 局域网 MQTT
- 打印机 IP、序列号、LAN access code 只保存在本机 `config.json`，不会上传

## 安装

1. 安装 Node.js 18 或更高版本。
2. 复制 `config.example.json` 为 `config.json`。
3. 填入云端地址、边缘令牌及每台打印机的本地连接信息。
4. 在云服务器设置相同的 `THREE_D_EDGE_AGENT_TOKEN`。
5. 先运行 `node --check agent.js`，再运行 `node agent.js`。

建议使用 Windows 任务计划程序，以“系统启动时”运行：

```text
程序: C:\Program Files\nodejs\node.exe
参数: agent.js
起始位置: 本目录的绝对路径
```

## 上线验收

先选一台空闲测试机验证状态连接，再开始打印测试件，依次验证：

1. 云端状态、文件名和进度能刷新；
2. 管理员发出暂停后打印机进入 `PAUSE`；
3. 管理员发出恢复后打印机回到 `RUNNING`；
4. 普通 3D 岗位没有控制按钮且调用接口返回 403；
5. 断开本机外网后，云端历史仍可查看，实时状态转为离线；
6. 恢复外网后，代理自动重连并继续上报。

不同固件可能调整未公开的 LAN MQTT 行为，因此远程控制必须完成现场验收后再正式启用。云端不会尝试直接连接打印机私网。
