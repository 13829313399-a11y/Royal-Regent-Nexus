# 任务分级与协作约定 V2

## 路由与单一负责人

| 类型 | 默认执行路径 | 验证与审查 |
| --- | --- | --- |
| 微小、确定、低影响 | 当前合适主线程直做；短检索、单处文案、一次命令不开代理 | 相关差异及必要视觉检查 |
| 普通且契约明确 | Terra/medium 主线程完成表单/API 接线、普通组件与已定位缺陷 | 相关行为测试、适用类型检查；集成批次的必要构建 |
| 窄范围重复批量 | 收益抵消交接时一个 Luna/low `rrn_easy`；否则主线程直做 | 原负责人核对样例与真实测试 |
| 高影响或高不确定性 | Astra/high 主线程或一个 `rrn_core` 连贯设计、实现、关键回归与修复 | 高影响最终差异独立 `rrn_reviewer` 审查 |

权限/厂区作用域、金额、库存、排产、导入迁移、审批状态机、跨模块契约和复杂新业务闭环属于强语义；开放式高要求 UI 也不能当成便宜 CSS 批次。纯视觉任务是否独立审查取决于风险。
权限文件中的注释未必高影响，前端一行厂区过滤却可能高影响。未知事实先查证，不能靠提高 effort 或让 Luna 猜业务。

一个复杂工作包只有一个主要语义负责人。Astra 主线程已掌握上下文时不再开 architect/core 重读同题。Terra 将难题交 core 后协调目标、文件归属和验收，不重新推导或用轻模型改写已审查的核心。`rrn_architect` 只用于独立设计交付/架构论证；批准文档是输入契约，有代码冲突再提出调整。

## 派发与上下文

只在真正派发时形成工作包，跨会话/工具/多人交接才落盘：

```text
目标：用户行为或待回答问题
起点：HEAD、相关未提交改动及归属
证据：文件/符号、记忆标题、确认事实
契约：API、状态、厂区、计算与异常语义
范围：可写文件、共享文件、不能覆盖的改动
验收：样例、测试或浏览器路径
未知：缺失业务事实、环境限制
返回：状态、改动、验证命令/退出结果、确证发现、证据、剩余风险
```

不复制全量记忆、仓库树、源码或长日志；关键契约不可为缩短提示而丢失。默认最小必要历史，先核对当前工具 schema，不捏造参数。依赖无法可靠压缩的对话决策时允许必要历史。集成者按风险检查原始 diff 和契约，不能只信摘要。

## 并发、升级与生命周期

普通任务默认 0 次派生，有实际收益最多一个工作包。单个复杂批次通常一个 core，高影响再顺序一个 reviewer；Astra 主线程通常省去 core。大型模块按可验收垂直批次推进，不逐文件派发。次数是软目标，不是付费硬限额。

默认最多 1 个同时打开的子线程，不含主线程。只有真实独立且需要提速时才考虑受支持的任务级并发 2；无法核实覆盖能力则串行，不改共享默认或发明预算键。

仅主线程派发，子代理不得再派生。六角色声明 `[agents].enabled=false`；实际工具屏蔽需运行时核实。返回完整结果、记录必要摘要后，用当前工具支持的方式结束闲置线程。reviewer 前先释放 core；修复前释放 reviewer，支持时恢复原 core，否则给新负责人必要 diff 和失败证据。无关模块不复用长上下文；关闭线程不会退还已消耗用量。没有关闭/恢复工具时不要把 interrupt 当成已释放槽位。

确定错误由原负责人按失败证据修复；首次失败揭示未知业务规则或高影响语义就交 Astra，不逐级试错。普通局部问题一次有效修复后仍同类失败且无新根因证据时升级或重新定位。环境、依赖、权限、服务或测试数据缺失先按环境处理。Astra 也不得无限重试；汇总已排除原因、真实错误、下一条可验证假设，不召集同级投票或虚报成功。

## 文件归属与集成

一文件一写者；只有独立文件、确定契约才并行。共享 `src/router/index.ts`、`src/style.css`、`package.json`/锁文件、`backend/app/main.py`、模型及 Alembic 链指定负责人。迁移负责人协调 revision/down_revision，集成者验证最终链，不能各自猜 head。
多人用独立分支/worktree，但子代理不自动隔离。保留用户及其他工作；未经当前用户明确要求，不 commit、push、开 PR 或同步远程。

## 验证与审查

检查匹配行为，沿用真实脚本。高影响覆盖正常、异常、边界及适用跨厂区/状态/并发样例。实现稳定、测试证据齐备后安排独立最终审查；审查者亲自读原始代码与契约，报告位置、触发、影响、证据和最小验证，不做偏好重构。原负责人修复，复审聚焦发现及影响范围。
只读角色不运行写缓存、产物或数据库的测试；由有权限的执行者完成并如实报告未执行项。同一最终 diff、依赖、测试数据和环境下复用有效证据；仅 HEAD 相同不代表工作树相同，输入变化就重新判断覆盖。集成者仍完成最终必要检查，不能永远用局部检查代替集成。

## 档位与费用证据

xhigh 仅在具体难题有证据且运行时支持真实覆盖时启用；提示词自称切换无效，不反复重写共享 TOML 模拟动态路由。规划档位单独核对。目标模型不可用时如实记录，关键工作不静默降级。
并发上限不限制总派生数；角色、沙箱声明与实际生效分开报告。账户用量、credits、token 不混算；输入/缓存/推理/父子累计口径不明时保留 unknown，不能重复加总。没有可比任务、同等质量和真实用量对照，不宣称节省百分比，也不自动重跑业务任务制造样本。
