# Royal-Regent-Nexus 模型路由 V2

日常 Terra/medium 主线程直接完成明确任务，默认零派生。按业务影响与不确定性分级，不按文件数量或行数判断。

复杂工作由 Astra/high 连贯负责必要设计、核心实现、关键回归与修复。主线程已是 Astra 就自己做；否则按需一个 `rrn_core`。`rrn_architect` 仅作独立设计交付，已有批准方案作为契约，不重复设计。

足够成批、完全确定的机械任务才考虑 `rrn_easy`；普通独立工作用 `rrn_worker`；有实际检索隔离收益才用 `rrn_scout`。高影响最终差异保留独立 `rrn_reviewer`，不能用费用理由删除关键测试或审查。

仅主线程派发；默认最多一个同时打开的子线程。最小必要上下文、一文件一写者、按证据升级；文件声明不是运行时强制或费用硬上限。不能调用目标角色时报告限制，不静默降级。

详细分级、重试、生命周期及工作包读取 `references/task-routing.md`。
仓库入口和实际验证命令按需读取 `references/repo-map.md`。
配置加载、实际模型与沙箱需要当前 App 元数据佐证；模型自称不算证据。
